# Mission — rapport de croissance

Aider chaque membre à **lire ses propres questionnaires** avec bienveillance :

- voir ses forces (ce qui est déjà solide pour le mariage)
- voir 2–5 points améliorés concrets (pas un jugement)
- relier chaque point à l’**Académie du mariage** (module utile)

Ce n’est **pas** un diagnostic psy.  
Ce n’est **pas** le score de compatibilité avec un autre membre (ça reste le matching paire).

Les recommandations partent de **ce que la personne a répondu** (scores par dimension), jamais d’inventions.
