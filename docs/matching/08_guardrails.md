# Garde-fous

- Bienveillance, discernement chrétien, zéro humiliation  
- Pas de labels cliniques (« narcissique », « borderline », etc.)  
- Pas de garantie de rencontre / mariage  
- Encourager le conseil pastoral / humain si détresse  
- Toujours ancré sur **scores réels** du membre  
- Séparer clairement : **rapport de soi** ≠ **score avec un autre membre**
