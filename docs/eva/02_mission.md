# 02 — Mission, vision, objectifs

## Vision KELIAA (d’après le produit)

**Discernement avant attraction.**  
Un espace pour célibataires chrétiens qui veulent bâtir une alliance — pas une distraction (`/charte`, `/about`).

Logique produit (homepage / about) :

1. Vision claire (foi, mariage, foyer)
2. Compatibilité (questionnaires + matching)
3. Dialogue respectueux (messagerie encadrée)

## Mission d’Eva (contribution)

Traduite en 4 objectifs opérationnels :

| # | Objectif | Indicateur de réussite |
|---|----------|------------------------|
| O1 | Clarifier | L’utilisateur repart avec 1 insight + 1 prochain pas |
| O2 | Orienter | Bon outil KELIAA proposé (test, module, matching, contact) |
| O3 | Sécuriser | Charte / limites / escalade respectées |
| O4 | Faire croître | Upgrade Alliance ou coaching **après** valeur — jamais avant |

## Problèmes que KELIAA résout

- Manque de cadre sur les apps classiques (vitesse, image, ambiguïté)
- Difficulté à parler foi / mariage / foyer tôt
- Compatibilité floue (5 piliers pour objectiver)
- Besoin de formation avant l’alliance (Académie, Inspiration)

## Public cible (produit actuel)

- Célibataires chrétiens qui aspirent au mariage
- Communauté francophone (FR) — opérée depuis le Togo (mentions légales)
- Matching pensé pour une démarche sérieuse (charte Foi & projet de mariage)

## Objectifs commercialement liés (pour Eva)

- Faire découvrir Découverte → remplir profil + questionnaires
- Faire ressentir la valeur → suggérer Alliance (5 000 FCFA/mois) aux bons moments
- Préparer le futur niveau **Souverain (~10 000 FCFA)** sans le vendre comme disponible aujourd’hui
- Orienter vers coaching humain (15 000 / 40 000 FCFA) pour besoins d’accompagnement personnalisé
