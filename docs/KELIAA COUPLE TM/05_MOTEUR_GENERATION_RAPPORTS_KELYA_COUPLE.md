# 05 --- MOTEUR DE GÉNÉRATION DES RAPPORTS

# KELYA COUPLE™

## Architecture éditoriale, personnalisation, niveaux d'offre, recommandations, exercices et plans d'action

**Document maître pour transformer les résultats du moteur de matching
en rapports relationnels complets, humains et personnalisés**

------------------------------------------------------------------------

# 1. OBJECTIF DU DOCUMENT

Ce document définit la manière dont KELYA COUPLE transforme les
résultats structurés du moteur de scoring et de matching en un véritable
rapport personnalisé.

Le moteur ne doit jamais simplement afficher des scores.

Il doit transformer les données en une **lecture relationnelle
compréhensible, nuancée, utile et directement exploitable par le
couple**.

Le résultat attendu n'est pas une fiche technique.

Le résultat attendu est un véritable dossier personnalisé que deux
personnes peuvent lire ensemble, télécharger, imprimer, annoter et
utiliser comme support de conversation et de travail.

------------------------------------------------------------------------

# 2. PRINCIPE FONDAMENTAL

Le moteur doit suivre cette chaîne :

``` text
RÉPONSES
↓
SCORES INDIVIDUELS
↓
MATCHING
↓
INTERPRÉTATION
↓
PERSONNALISATION
↓
RÉDACTION
↓
RECOMMANDATIONS
↓
EXERCICES
↓
PLAN D'ACTION
↓
CONCLUSION
↓
RAPPORT FINAL
```

Le moteur de rapport ne doit jamais accéder directement aux réponses
brutes pour improviser une interprétation sans passer par la structure
méthodologique du Document 04.

------------------------------------------------------------------------

# 3. LE RAPPORT N'EST PAS UN EXPORT DE DONNÉES

Interdit :

> Communication : 72/100\
> Finances : 45/100\
> Conflits : 61/100\
> Action : améliorer la communication.

Ce format est insuffisant.

Le rapport doit expliquer :

-   ce que les résultats signifient ;
-   pourquoi cette dimension ressort ;
-   comment elle peut se manifester dans la relation ;
-   ce que chacun peut comprendre ;
-   ce que chacun peut ajuster ;
-   ce que le couple peut construire ;
-   comment commencer concrètement.

------------------------------------------------------------------------

# 4. LE RAPPORT DOIT ÊTRE RÉDIGÉ COMME UN DOSSIER

Le rapport doit avoir une continuité narrative.

Le lecteur doit avoir l'impression de suivre une véritable analyse.

Il doit pouvoir passer naturellement de :

> « Voici ce que nous observons »

à :

> « Voici ce que cela peut vouloir dire »

puis :

> « Voici ce que vous pouvez en faire ».

------------------------------------------------------------------------

# 5. PRINCIPES DE RÉDACTION

Le moteur doit respecter les principes suivants :

-   écrire en paragraphes ;
-   aérer les sections ;
-   éviter l'effet liste ;
-   expliquer les résultats ;
-   utiliser des transitions ;
-   conclure les grandes parties ;
-   proposer des actions concrètes ;
-   éviter les formulations mécaniques ;
-   éviter les répétitions ;
-   conserver un ton humain ;
-   respecter la dignité des deux partenaires.

Les paragraphes doivent être suffisamment aérés pour permettre une
lecture confortable, mais le document ne doit pas être composé de
phrases isolées ligne par ligne.

------------------------------------------------------------------------

# 6. TON DU RAPPORT

Le ton doit être :

**bienveillant, adulte, professionnel, chaleureux, nuancé, direct et
responsabilisant.**

Le rapport ne doit être :

-   ni froid ;
-   ni infantilisant ;
-   ni moralisateur ;
-   ni dramatique ;
-   ni excessivement psychologisant ;
-   ni commercial ;
-   ni rempli de jargon.

------------------------------------------------------------------------

# 7. LE RAPPORT S'ADRESSE AUX DEUX PERSONNES

Le texte doit utiliser :

> « vous »

lorsqu'il s'adresse au couple.

Pour les analyses individuelles :

> « Pour vous, ... »

ou le prénom lorsque cela améliore naturellement la personnalisation.

Exemple :

> **Pour Sarah, cette dimension semble actuellement représenter un
> besoin important de sécurité et de clarté.**

Puis :

> **Pour Thomas, l'enjeu semble davantage se situer dans la manière
> d'exprimer ses besoins sans se retirer de la conversation.**

------------------------------------------------------------------------

# 8. NE PAS CRÉER DE COUPABLE

Le rapport ne doit jamais désigner :

> le problème du couple = une personne.

Même lorsqu'un score individuel est nettement plus faible.

Préférer :

> « Cette dimension semble représenter un axe de progression plus
> important pour vous actuellement. »

Puis expliquer ce que le partenaire peut comprendre sans porter la
responsabilité à sa place.

------------------------------------------------------------------------

La structure de référence est :

``` text

MESSAGE D'ACCUEIL
↓

↓
SYNTHÈSE DE VOTRE COUPLE
↓
VOTRE SCORE GLOBAL
↓

↓
VOS PRINCIPALES CONVERGENCES
↓
VOS DIFFÉRENCES
↓
VOS ZONES DE VIGILANCE
↓

↓
PROFIL INDIVIDUEL B
↓
```

Toutes les sections ne sont pas nécessairement présentes avec la même
profondeur dans toutes les offres.

------------------------------------------------------------------------

# 10. COUVERTURE

La couverture doit être élégante.

Elle doit contenir :

> **KELYA COUPLE™**

> **Bilan de Compatibilité & Dynamique du Couple**

Puis :

> **\[Prénom\] & \[Prénom\]**

Et la date.

Pour une version Premium Plus, la mention :

> **PREMIUM PLUS**

doit être clairement visible.

------------------------------------------------------------------------

# 11. MESSAGE D'ACCUEIL

Le rapport doit commencer par un véritable texte d'accueil.

Exemple :

> **Bienvenue dans votre bilan KELYA COUPLE.**
>
> Vous avez choisi de prendre un temps pour regarder votre relation
> autrement : non pas uniquement à travers ce qui fonctionne ou ce qui
> ne fonctionne pas, mais à travers vos deux manières de penser, de
> ressentir, de décider, de communiquer et de construire.
>
> Ce dossier a été conçu pour vous aider à mieux comprendre ce qui vous
> rapproche, à mettre des mots sur vos différences et à identifier les
> sujets qui méritent aujourd'hui votre attention.
>
> Prenez le temps de le lire. Certaines pages vous confirmeront
> probablement ce que vous saviez déjà. D'autres pourront vous
> surprendre. L'objectif n'est pas de chercher qui a raison, mais de
> mieux comprendre ce qui se passe entre vous afin de pouvoir agir avec
> davantage de conscience.

------------------------------------------------------------------------

# 12. COMMENT LIRE LE BILAN

Cette section est obligatoire.

Elle doit expliquer que :

> Le bilan n'est pas un verdict.

Puis :

> Un score élevé ne signifie pas que votre couple ne rencontrera jamais
> de difficulté. Un score faible ne signifie pas non plus que votre
> relation est condamnée.

Puis expliquer :

> Les résultats doivent être lus comme une photographie de vos réponses
> au moment du questionnaire.

Puis :

> Ce qui compte le plus n'est donc pas uniquement votre score global,
> mais les dimensions qui composent ce score, les convergences que vous
> pouvez préserver et les différences que vous pouvez choisir de
> travailler.

------------------------------------------------------------------------

# 13. SYNTHÈSE DE VOTRE COUPLE

Cette section doit être rédigée en plusieurs paragraphes.

Elle répond à :

> **Quel est le portrait général de ce couple ?**

Elle doit intégrer :

-   niveau global ;
-   forces ;
-   différences ;
-   priorités ;
-   dynamique générale.

Elle doit éviter de répéter mécaniquement tous les scores.

------------------------------------------------------------------------

# 14. LE SCORE GLOBAL

Présenter le score de manière visuelle.

Exemple :

> **72/100**

Puis un libellé :

> **Une base relationnelle favorable, avec plusieurs sujets importants à
> clarifier.**

Puis plusieurs paragraphes expliquant le score.

------------------------------------------------------------------------

# 15. INTERPRÉTATION DU SCORE GLOBAL

Le moteur doit produire une interprétation adaptée.

## Score très faible

Ne jamais écrire :

> « Vous êtes incompatibles. »

Écrire plutôt :

> **Vos réponses montrent actuellement des écarts importants sur
> plusieurs dimensions structurantes. Ce résultat ne permet pas de
> conclure que votre relation est impossible. Il vous invite cependant à
> prendre au sérieux certains sujets qui pourraient devenir difficiles
> s'ils restent non discutés.**

## Score intermédiaire

> **Votre couple présente plusieurs ressources, mais aussi des
> différences qui méritent d'être clarifiées. Votre potentiel ne réside
> pas dans le fait de devenir identiques, mais dans votre capacité à
> comprendre vos différences et à construire des accords qui respectent
> chacun.**

## Score élevé

> **Votre bilan montre une forte convergence sur de nombreuses
> dimensions. Cette proximité constitue une ressource importante. Votre
> enjeu sera aussi de préserver ces ressources lorsque des périodes de
> stress, de changement ou de désaccord apparaîtront.**

------------------------------------------------------------------------

# 16. RÈGLE DU SCORE DE 15 %

Le système doit disposer d'une règle explicite.

Si :

``` text
overall_score <= 20
```

le rapport doit obligatoirement :

-   contextualiser ;
-   éviter tout verdict ;
-   détailler les dimensions responsables ;
-   identifier les ressources restantes ;
-   proposer des conversations ;
-   proposer des actions ;
-   proposer un accompagnement lorsque pertinent.

Le système ne doit jamais générer :

> « Vous n'êtes pas compatibles. »

------------------------------------------------------------------------

# 17. VOS GRANDES FORCES

Cette section doit identifier généralement :

``` text
3 à 5 forces principales
```

Pour chaque force :

1.  nom ;
2.  explication ;
3.  manifestation possible ;
4.  raison pour laquelle elle est importante ;
5.  manière de la préserver.

------------------------------------------------------------------------

# 18. EXEMPLE DE FORCE RÉDIGÉE

> **Une vision commune de votre avenir**
>
> Vos réponses montrent une proximité importante concernant votre
> manière d'imaginer les prochaines étapes de votre vie. Vous semblez
> partager plusieurs repères sur ce que vous souhaitez construire, ce
> qui peut faciliter les grandes décisions lorsque votre environnement
> change.
>
> Cette convergence est précieuse, mais elle ne doit pas devenir
> automatique. Prenez régulièrement le temps de vérifier que vos projets
> évoluent encore dans la même direction et que chacun se sent
> réellement inclus dans les décisions importantes.
>
> **Votre point d'appui :** utilisez cette vision commune pour créer des
> décisions concrètes plutôt que de la considérer comme acquise.

------------------------------------------------------------------------

# 19. VOS PRINCIPALES CONVERGENCES

Cette section doit expliquer :

-   où vous vous ressemblez ;
-   où vos attentes sont proches ;
-   pourquoi cela peut faciliter la relation ;
-   comment utiliser ces convergences.

Chaque convergence doit être rédigée.

------------------------------------------------------------------------

# 20. VOS DIFFÉRENCES

Le mot « différence » doit être utilisé sans connotation négative.

Chaque différence doit répondre à :

> **En quoi êtes-vous différents ?**

> **Pourquoi cette différence peut-elle apparaître dans votre quotidien
> ?**

> **Que devez-vous clarifier ?**

------------------------------------------------------------------------

# 21. EXEMPLE DE DIFFÉRENCE

> **Votre rapport au temps et aux décisions**
>
> Vos réponses suggèrent que vous n'avez pas le même rythme lorsqu'une
> décision importante doit être prise. L'un de vous semble avoir besoin
> d'avancer rapidement afin de réduire l'incertitude, tandis que l'autre
> semble avoir besoin de davantage de temps pour réfléchir avant de se
> positionner.
>
> Cette différence peut devenir une source de tension si elle est
> interprétée comme un manque d'implication d'un côté ou comme une
> pression de l'autre.
>
> Votre enjeu n'est donc pas nécessairement de choisir quel rythme est
> le bon. Il consiste plutôt à définir un fonctionnement qui permette à
> chacun de participer à la décision sans se sentir poussé ou ignoré.

------------------------------------------------------------------------

# 22. VOS ZONES DE VIGILANCE

Cette section doit être plus profonde.

Pour chaque zone :

-   observation ;
-   contexte ;
-   risque relationnel potentiel ;
-   ce qu'il faut clarifier ;
-   action recommandée.

------------------------------------------------------------------------

# 23. RÈGLE SUR LES ZONES DE VIGILANCE

Une zone de vigilance ne doit jamais être écrite comme une condamnation.

Éviter :

> « Votre couple a un gros problème financier. »

Préférer :

> **« Les réponses montrent une différence importante dans votre manière
> d'envisager la gestion financière. Si cette différence reste
> implicite, elle pourrait devenir une source de tension lorsque vous
> devrez prendre des décisions concrètes. »**

------------------------------------------------------------------------

# 24. PROFIL INDIVIDUEL --- PARTICIPANT A

Cette partie doit être suffisamment développée pour que la personne se
reconnaisse.

Elle peut contenir :

-   portrait relationnel ;
-   forces ;
-   besoins ;
-   tendances ;
-   points de vigilance ;
-   axe de progression.

Le texte doit rester descriptif.

------------------------------------------------------------------------

# 25. STRUCTURE DU PROFIL INDIVIDUEL

``` text
Votre manière de fonctionner
↓
Vos principales ressources
↓
Ce dont vous avez probablement besoin
↓
Ce qui peut vous mettre en difficulté
↓
Ce que votre partenaire gagnerait à comprendre
↓
Votre axe de progression
↓
Votre engagement personnel
```

------------------------------------------------------------------------

# 26. « CE QUE VOTRE PARTENAIRE GAGNERAIT À COMPRENDRE »

Cette section est particulièrement importante.

Elle permet d'éviter que le profil individuel soit uniquement
autocentré.

Exemple :

> **Votre besoin de recul n'est pas nécessairement un désintérêt.**
>
> Lorsque la tension monte, vous pouvez avoir besoin de prendre du recul
> avant de pouvoir parler calmement. Pour votre partenaire, ce retrait
> peut cependant être interprété comme un refus de communiquer.
>
> Une piste importante consiste donc à ne pas seulement demander de
> l'espace, mais à expliquer ce dont vous avez besoin et à rassurer
> l'autre sur votre intention de revenir à la conversation.

------------------------------------------------------------------------

# 27. PROFIL INDIVIDUEL --- PARTICIPANT B

La même profondeur doit être appliquée au second partenaire.

Le moteur ne doit pas écrire un profil beaucoup plus court pour le
second participant.

Les deux personnes doivent recevoir une analyse équilibrée.

------------------------------------------------------------------------

# 28. VOTRE DYNAMIQUE À DEUX

Cette section constitue le cœur du rapport.

Elle doit expliquer :

-   comment les deux profils interagissent ;
-   quelles dynamiques sont favorables ;
-   lesquelles peuvent créer des cycles de tension ;
-   où les partenaires peuvent se soutenir ;
-   où ils doivent poser des limites ou accords.

------------------------------------------------------------------------

# 29. LES CYCLES RELATIONNELS

Lorsque les données le permettent, le moteur peut identifier un cycle.

Exemple :

``` text
A demande davantage de proximité
↓
B se sent sous pression
↓
B prend de la distance
↓
A ressent davantage d'insécurité
↓
A demande encore davantage de réassurance
```

Le rapport doit expliquer ce cycle sans désigner de coupable.

Puis :

> **La priorité n'est pas de déterminer qui commence. Elle consiste à
> interrompre le cycle.**

------------------------------------------------------------------------

# 30. EXEMPLE DE DYNAMIQUE RÉDIGÉE

> Vos réponses suggèrent une dynamique dans laquelle vos besoins peuvent
> involontairement se renforcer l'un l'autre. Lorsque vous ressentez de
> l'incertitude, vous pouvez chercher davantage de proximité et de
> clarification. Votre partenaire peut alors ressentir cette demande
> comme une pression et avoir tendance à prendre du recul. Ce recul peut
> à son tour augmenter votre besoin de réassurance.
>
> Ce mécanisme n'implique pas qu'une personne soit responsable de tout.
> Il montre plutôt comment deux stratégies individuelles peuvent
> s'alimenter mutuellement.
>
> Votre travail commun consistera donc à interrompre ce cycle plus tôt,
> avant qu'il ne devienne une confrontation.

------------------------------------------------------------------------

# 31. VOS PRIORITÉS

Le moteur doit sélectionner :

``` text
3 priorités principales
+
jusqu'à 2 priorités secondaires
```

Chaque priorité doit être expliquée.

------------------------------------------------------------------------

# 32. STRUCTURE D'UNE PRIORITÉ

``` text
Titre
↓
Pourquoi cette priorité ressort
↓
Ce que cela peut produire
↓
Ce que chacun peut travailler
↓
Ce que le couple doit décider
↓
Première action
↓
Exercice associé
↓
Ressource associée
```

------------------------------------------------------------------------

# 33. EXEMPLE DE PRIORITÉ

> **Priorité 1 --- Clarifier votre vision financière**
>
> Vos réponses montrent une différence importante dans votre manière
> d'envisager les dépenses, l'épargne et la responsabilité financière.
> Cette différence n'est pas nécessairement problématique en elle-même,
> mais elle peut devenir difficile lorsque les décisions financières
> deviennent communes.
>
> Pour vous, l'objectif n'est pas de déterminer qui gère mieux l'argent.
> Il est de rendre explicites vos règles de fonctionnement.
>
> Commencez par répondre chacun séparément à trois questions : «
> Qu'est-ce qu'une bonne gestion de l'argent signifie pour moi ? », «
> Qu'est-ce qui me sécurise financièrement ? » et « Sur quelles
> décisions ai-je besoin de garder une autonomie ? »
>
> Ensuite, comparez vos réponses et identifiez trois règles financières
> communes.

------------------------------------------------------------------------

# 34. RECOMMANDATIONS INDIVIDUELLES

Chaque partenaire doit recevoir des recommandations adaptées.

Une recommandation doit être :

-   concrète ;
-   réaliste ;
-   mesurable lorsque possible ;
-   directement reliée au résultat.

Éviter :

> « Travaillez sur vous. »

Préférer :

> « Lorsque vous sentez que la conversation devient trop intense,
> demandez une pause en précisant quand vous souhaitez reprendre la
> discussion. »

------------------------------------------------------------------------

# 35. RECOMMANDATIONS POUR LE COUPLE

Les recommandations communes doivent être formulées comme des directives
bienveillantes.

Exemple :

> **Pendant les deux prochaines semaines, choisissez un moment de 30
> minutes chaque semaine pour parler d'un seul sujet important.
> L'objectif n'est pas de résoudre immédiatement le problème, mais de
> vérifier que chacun a pu exprimer ce qu'il pense, ce qu'il ressent et
> ce dont il a besoin.**

------------------------------------------------------------------------

# 36. EXERCICES : RÈGLE GÉNÉRALE

Un exercice doit toujours être entièrement rédigé.

Il ne suffit pas d'écrire :

> « Exercice de communication »

ou :

> « Faire un exercice sur les finances ».

Le moteur doit générer :

-   le titre ;
-   l'objectif ;
-   l'introduction ;
-   la durée ;
-   le matériel éventuel ;
-   les consignes ;
-   les questions ;
-   l'espace de réflexion ;
-   la phase de partage ;
-   la conclusion ;
-   l'action suivante.

------------------------------------------------------------------------

# 37. MODÈLE D'EXERCICE

``` text
TITRE
Pourquoi cet exercice ?
Avant de commencer
Étape 1
Étape 2
Étape 3
Questions individuelles
Partage à deux
Ce que nous retenons
Notre décision
Notre prochaine action
```

------------------------------------------------------------------------

# 38. EXERCICE EXEMPLE --- « CE QUE J'AIMERAIS QUE TU COMPRENNES »

> **Pourquoi cet exercice ?**
>
> Certaines tensions apparaissent parce que nous répondons à ce que nous
> croyons comprendre plutôt qu'à ce que l'autre essaie réellement de
> nous dire. Cet exercice vous aide à ralentir et à écouter avant de
> chercher une solution.
>
> **Durée :** environ 30 minutes.
>
> Chacun prend dix minutes seul pour répondre aux questions suivantes :
>
> « Dans notre relation, je me sens particulièrement compris(e)
> lorsque... »
>
> « Il y a un sujet sur lequel j'aimerais que tu comprennes mieux mon
> besoin de... »
>
> « Lorsque nous sommes en désaccord, ce qui m'aide le plus est... »
>
> « Une chose que j'aimerais pouvoir te demander plus facilement est...
> »
>
> Ensuite, chacun lit ses réponses à l'autre sans être interrompu.
>
> La personne qui écoute ne cherche pas immédiatement à expliquer,
> corriger ou se défendre. Elle répond simplement :
>
> « Ce que je comprends de ce que tu viens de me dire, c'est... »
>
> Enfin, chacun complète :
>
> « Une chose que je peux faire différemment à partir de maintenant
> est... »

------------------------------------------------------------------------

# 39. ESPACE D'ÉCRITURE

Les exercices destinés au téléchargement doivent prévoir de vrais
espaces.

Le moteur de mise en page doit réserver suffisamment de place pour
écrire à la main.

Une page d'exercice ne doit pas être saturée de texte.

------------------------------------------------------------------------

# 40. EXERCICES INDIVIDUELS

Certains exercices doivent être réalisés séparément.

Exemple :

> **Ma définition d'une relation sécurisante**

Puis :

-   ce que j'attends ;
-   ce que je donne ;
-   ce que j'ai du mal à demander ;
-   ce que je peux ajuster.

------------------------------------------------------------------------

# 41. EXERCICES À DEUX

D'autres doivent être réalisés ensemble.

Exemple :

> **Notre accord sur les conflits**

Le couple doit définir :

-   comment demander une pause ;
-   combien de temps elle peut durer ;
-   comment reprendre la discussion ;
-   ce qui est interdit pendant un conflit ;
-   comment réparer après une dispute.

------------------------------------------------------------------------

# 42. PLAN D'ACTION

Le plan d'action doit transformer l'analyse en comportement.

Il doit éviter les grandes déclarations vagues.

Exemple :

``` text
SEMAINE 1
Conversation de 30 minutes sur les finances.

SEMAINE 2
Créer une règle de dépenses communes.

SEMAINE 3
Réviser la règle et ajuster.

SEMAINE 4
Faire un bilan ensemble.
```

------------------------------------------------------------------------

# 43. PLAN D'ACTION INDIVIDUEL

Chaque partenaire peut recevoir :

> **Mon engagement personnel**

Puis :

> « Cette semaine, je vais... »

Le système doit proposer une action précise.

------------------------------------------------------------------------

# 44. PLAN D'ACTION DU COUPLE

Le couple reçoit :

> **Notre engagement commun**

Puis trois à cinq actions.

Chaque action doit préciser :

-   quoi ;
-   quand ;
-   qui ;
-   comment savoir que c'est fait.

------------------------------------------------------------------------

# 45. RÈGLE DES PETITES ACTIONS

Les actions doivent être suffisamment petites pour être réellement
réalisées.

Éviter :

> « Améliorer notre communication. »

Préférer :

> « Pendant les deux prochaines semaines, nous consacrerons 20 minutes
> chaque dimanche à parler d'un sujet qui pourrait créer une tension
> pendant la semaine. »

------------------------------------------------------------------------

# 46. CONCLUSION DE CHAQUE GRANDE SECTION

Chaque section importante doit se terminer par une conclusion.

Exemple :

> **En résumé, votre proximité sur cette dimension constitue une vraie
> ressource. Votre travail ne consiste donc pas à la réparer, mais à la
> protéger et à l'utiliser lorsque vous rencontrerez des sujets plus
> difficiles.**

Il ne faut pas terminer brutalement une section après un graphique ou
une liste.

------------------------------------------------------------------------

# 47. CONCLUSION GÉNÉRALE

La conclusion générale doit être longue et personnalisée.

Elle doit reprendre :

-   ce qui ressort le plus ;
-   les principales forces ;
-   les principaux défis ;
-   les possibilités d'évolution ;
-   les premières actions.

Elle ne doit pas simplement répéter le résumé.

------------------------------------------------------------------------

# 48. EXEMPLE DE CONCLUSION

> **Votre bilan ne vous demande pas de devenir un couple parfait. Il
> vous invite à devenir un couple plus conscient de son
> fonctionnement.**
>
> Vous disposez de plusieurs ressources importantes, notamment une
> vision commune sur certains sujets essentiels et une capacité à vous
> rejoindre sur plusieurs valeurs. En parallèle, vos réponses font
> ressortir des différences qui pourraient devenir plus difficiles avec
> le temps si elles restent implicites, notamment autour de la gestion
> financière, des relations avec les familles et de la manière de gérer
> les désaccords.
>
> Ces différences ne définissent pas votre couple. Elles vous donnent
> des informations sur les conversations que vous avez intérêt à avoir.
>
> Commencez petit. Choisissez une seule priorité. Prenez un moment
> calme. Écoutez avant de chercher à convaincre. Cherchez à comprendre
> ce qui se trouve derrière la position de l'autre.
>
> Votre objectif n'est pas de supprimer toutes vos différences. Il est
> de construire une manière de vivre avec elles qui respecte chacun.
>
> **Ce bilan n'est donc pas une fin. C'est un point de départ.**

------------------------------------------------------------------------

# 49. PROCHAINE ÉTAPE

Après la conclusion, le rapport doit proposer une prochaine action
claire.

Exemple :

> **Votre première étape**
>
> Cette semaine, choisissez la priorité n°1 et réalisez l'exercice
> associé.

Puis :

> **Si vous sentez que certains sujets sont trop difficiles à travailler
> seuls, vous pouvez également choisir de vous faire accompagner.**

# 50. RESSOURCES

Les ressources doivent être sélectionnées selon les résultats.

Elles peuvent inclure :

-   ressources KELYA ;
-   séances ;
-   programmes ;
-   guides ;
-   exercices complémentaires ;
-   ressources externes ;
-   professionnels qualifiés.

Ne pas proposer dix ressources.

Proposer celles qui répondent réellement aux besoins détectés.

# 51. ORIENTATION THÉRAPEUTIQUE

Lorsque le moteur identifie un besoin pouvant nécessiter un
accompagnement professionnel, le rapport peut proposer :

> **Certaines situations gagnent à être travaillées avec un
> professionnel qualifié. Si vous sentez que vos échanges deviennent
> trop difficiles, qu'un sujet revient sans cesse ou que vous ne
> parvenez pas à avancer seuls, demander un accompagnement peut être une
> démarche de maturité et non un échec.**

Puis proposer les ressources appropriées.

Le système ne doit pas poser de diagnostic.

# 56. SIMULATIONS PREMIUM PLUS

Exemple :

> **Simulation --- Une décision financière importante**
>
> Imaginez que vous devez prendre ensemble une décision qui représente
> une dépense importante pour votre foyer.
>
> Avant de discuter, chacun répond séparément :
>
> « À partir de quel montant est-il important que nous décidions
> ensemble ? »
>
> « Qu'est-ce qui me rassure avant une dépense importante ? »
>
> « Quelle marge d'autonomie financière est importante pour moi ? »
>
> « Que ferais-je si nous n'étions pas d'accord ? »
>
> Ensuite, comparez vos réponses.
>
> L'objectif n'est pas de trouver immédiatement une règle parfaite. Il
> est d'identifier les différences de raisonnement qui pourraient
> devenir importantes dans une situation réelle.

------------------------------------------------------------------------

# 57. PROTOCOLES PREMIUM PLUS

Un protocole doit être complet.

Exemple :

> **Protocole de conversation difficile**
>
> **Étape 1 --- Nommer le sujet**
>
> Une personne décrit le sujet en une phrase sans accusation.
>
> **Étape 2 --- Dire son expérience**
>
> Chacun explique ce qu'il ressent, ce qu'il pense et ce dont il a
> besoin.
>
> **Étape 3 --- Reformuler**
>
> Chacun reformule ce qu'il a compris.
>
> **Étape 4 --- Identifier le besoin commun**
>
> Cherchez ce que vous essayez tous les deux de protéger.
>
> **Étape 5 --- Construire un accord**
>
> Définissez une règle concrète.
>
> **Étape 6 --- Vérifier**
>
> Fixez un moment pour vérifier si l'accord fonctionne.

> 3.  ...

------------------------------------------------------------------------

# 60. PHASE 1 --- EXEMPLE

> **Semaines 1 et 2 : comprendre votre fonctionnement**
>
> Pendant ces deux premières semaines, votre objectif n'est pas de
> changer immédiatement votre relation. Il est d'observer.
>
> Une fois par semaine, prenez 20 à 30 minutes pour répondre ensemble à
> une question issue de votre bilan.
>
> À la fin de chaque conversation, chacun complète :
>
> « Ce que j'ai mieux compris de toi aujourd'hui est... »
>
> « Ce que j'aimerais continuer à explorer est... »

------------------------------------------------------------------------

# 61. PHASE 2 --- EXEMPLE

> **Semaines 3 et 4 : clarifier vos accords**
>
> Choisissez deux des priorités identifiées dans votre rapport.
>
> Pour chacune, définissez ce que vous acceptez, ce que vous n'acceptez
> pas et ce qui doit être renégocié lorsque votre situation change.
>
> Écrivez vos accords.
>
> Ne comptez pas uniquement sur votre mémoire.

------------------------------------------------------------------------

# 62. PHASE 3 --- EXEMPLE

> **Semaines 5 à 8 : expérimenter**
>
> Choisissez une nouvelle manière de fonctionner et testez-la pendant
> quatre semaines.
>
> À la fin de chaque semaine, posez-vous trois questions :
>
> « Qu'est-ce qui a fonctionné ? »
>
> « Qu'est-ce qui a été difficile ? »
>
> « Que devons-nous ajuster ? »

------------------------------------------------------------------------

# 63. PHASE 4 --- EXEMPLE

> **Semaines 9 à 12 : consolider**
>
> Relisez vos premiers résultats.
>
> Identifiez les changements observés.
>
> Décidez des habitudes que vous souhaitez conserver.
>
> Puis écrivez une phrase qui résume la manière dont vous souhaitez
> continuer à construire votre relation.

# 70. ÉVITER LA RÉPÉTITION

Le mécanisme est expliqué.

Une action est proposée.

Le couple pratique.

### Plan d'action

Le couple met en œuvre.

Ainsi, la répétition devient une progression.

# 83. CONTRÔLE DE NON-CONTRADICTION

Le moteur doit détecter les contradictions.

Exemple :

Page 8 :

> « Votre communication est une force majeure. »

Page 20 :

> « Votre principale difficulté est votre communication. »

Une telle contradiction doit déclencher une vérification.

------------------------------------------------------------------------

# 84. CONTRÔLE DE SURINTERPRÉTATION

Le système doit vérifier que le texte ne va pas au-delà des données.

Interdit :

> « Vous avez peur de l'abandon. »

si le questionnaire ne permet pas de soutenir cette formulation.

Préférer :

> « Vos réponses suggèrent un besoin important de réassurance dans
> certaines situations. »

------------------------------------------------------------------------

# 85. CONTRÔLE DE LANGAGE

Le système doit rechercher les formulations interdites ou à éviter :

``` text
incompatible
condamné
impossible
âme sœur
garantie
rupture certaine
divorce certain
diagnostic
trouble
pathologique
toxique
```

Ces termes peuvent éventuellement apparaître dans un contexte
pédagogique très spécifique, mais ils ne doivent jamais être utilisés
comme verdict automatique sur le couple.

------------------------------------------------------------------------

# 86. CONTRÔLE DE RESPONSABILITÉ

Rechercher les formulations :

> « C'est à cause de lui. »

> « C'est à cause d'elle. »

> « Votre partenaire est le problème. »

et les remplacer par des formulations relationnelles ou individuelles
plus justes.

# 90. RAPPORT PERSONNALISÉ VS MODÈLE

Les modèles servent de structure.

-   les explications ;
-   les exemples ;
-   les priorités ;
-   les exercices ;

# 91. CAS DE TEST --- COUPLE TRÈS CONVERGENT

Le rapport doit montrer :

-   les ressources ;
-   ce qui peut être préservé ;
-   les éventuelles zones de croissance ;
-   les pratiques de prévention.

Il ne doit pas inventer des problèmes pour remplir le rapport.

------------------------------------------------------------------------

# 92. CAS DE TEST --- COUPLE TRÈS DIVERGENT

Le rapport doit :

-   expliquer les différences ;
-   identifier les sujets structurants ;
-   distinguer complémentarité et conflit ;
-   proposer des conversations ;
-   proposer des actions.

Il ne doit pas conclure automatiquement à l'incompatibilité.

------------------------------------------------------------------------

# 93. CAS DE TEST --- SCORE GLOBAL FAIBLE

Le rapport doit être plus explicatif.

Il doit montrer :

-   pourquoi le score est faible ;
-   quelles dimensions l'expliquent ;
-   quelles ressources subsistent ;
-   quelles conversations sont prioritaires ;
-   quelles actions peuvent être entreprises.

------------------------------------------------------------------------

# 94. CAS DE TEST --- SCORE GLOBAL ÉLEVÉ

Le rapport doit rester utile.

Il doit :

-   identifier les forces ;
-   montrer les zones à préserver ;
-   proposer des pratiques de prévention ;
-   éviter le discours « vous êtes parfaits ».

------------------------------------------------------------------------

# 95. CAS DE TEST --- UNE PERSONNE TRÈS DIFFÉRENTE

Le rapport doit éviter de transformer le partenaire avec le score élevé
en juge.

Exemple :

> « Votre partenaire semble avoir davantage de facilité sur cette
> dimension. Cela ne signifie pas qu'il ou elle doit vous apprendre à
> fonctionner. Votre travail peut être différent, tandis que son rôle
> peut être de comprendre et soutenir sans prendre la responsabilité de
> votre progression. »

------------------------------------------------------------------------

# 96. CAS DE TEST --- BESOIN DE THÉRAPIE

Le rapport doit rester prudent.

Il peut dire :

> « Un accompagnement professionnel pourrait vous aider à travailler ce
> sujet dans un cadre sécurisé. »

Il ne doit pas dire :

> « Vous avez besoin de thérapie parce que votre couple est
> dysfonctionnel. »

------------------------------------------------------------------------

# 97. RÈGLE DE COMMERCIALISATION

Le rapport peut orienter vers une offre KELYA, mais la recommandation
doit découler du besoin.

Exemple :

> **Si vous souhaitez aller plus loin sur cette dimension, KELYA propose
> une session consacrée à...**

Pas :

> **Achetez maintenant notre programme.**

-   informations nécessaires.

``` text
DO NOT PUBLISH
```

# 111. VERSIONNAGE DU CONTENU

Les contenus rédactionnels doivent être versionnés.

Exemple :

``` text
CONTENT_LIBRARY_VERSION = 1.0
```

Un rapport doit conserver :

``` text
ENGINE_VERSION
CONTENT_VERSION
REPORT_VERSION
```

# 112. REPRODUCTIBILITÉ

Le système doit pouvoir expliquer avec quelles versions un rapport a été
produit.

Exemple :

``` text

```

# 113. RÈGLE DE NON-RÉÉCRITURE DES DONNÉES

Le moteur de rapport ne doit jamais modifier les données de scoring.

Il les lit.

Il les interprète.

Il produit du texte.

La séparation doit rester stricte.

------------------------------------------------------------------------

# 114. RÈGLE DE TRANSPARENCE

Si une donnée manque :

> ne pas inventer.

Le moteur doit soit :

-   demander une donnée ;
-   utiliser une formulation neutre ;
-   omettre la partie concernée.

------------------------------------------------------------------------

# 115. RÈGLE DE PERSONNALISATION

Plus le résultat est spécifique, plus le texte doit l'être.

Éviter les phrases génériques qui pourraient être appliquées à n'importe
quel couple.

Exemple faible :

> « La communication est importante dans un couple. »

Exemple utile :

> « Dans votre cas, la communication ressort moins comme un problème de
> fréquence que comme une différence de rythme : l'un de vous semble
> chercher une clarification immédiate tandis que l'autre a besoin de
> temps avant de pouvoir répondre. »

------------------------------------------------------------------------

# 116. RÈGLE DE VALEUR

Chaque page doit répondre à une question utile.

Exemples :

> Qu'est-ce que cela dit de nous ?

> Pourquoi cela compte ?

> Que pouvons-nous faire ?

> Comment commencer ?

Si une page n'apporte aucune réponse, elle doit être supprimée.

------------------------------------------------------------------------

# 117. RÈGLE DE DENSITÉ

Le rapport doit être riche mais respirable.

Un bloc doit être suffisamment développé pour être utile.

Mais une page ne doit pas contenir :

-   quinze encadrés ;
-   dix graphiques ;
-   trente bullets ;
-   des paragraphes interminables.

Le design doit permettre la lecture progressive.

------------------------------------------------------------------------

# 118. RÈGLE D'IMPRESSION

Le rapport doit pouvoir être imprimé.

Les exercices doivent avoir suffisamment d'espace.

Les pages contenant des questions doivent prévoir des zones blanches.

Les recommandations peuvent être imprimées séparément.

------------------------------------------------------------------------

# 119. RÈGLE DE RETOUR

Le couple doit pouvoir revenir au rapport plusieurs fois.

Le rapport doit donc être compréhensible même plusieurs semaines après
le test.

Éviter les formulations dépendantes d'un contexte temporaire non
expliqué.

------------------------------------------------------------------------

# 120. RÈGLE DE CONCLUSION DU RAPPORT

La dernière impression doit être :

> **« Nous avons appris quelque chose d'utile sur notre couple et nous
> savons quoi faire ensuite. »**

Elle ne doit pas être :

> « Nous avons reçu un score. »
