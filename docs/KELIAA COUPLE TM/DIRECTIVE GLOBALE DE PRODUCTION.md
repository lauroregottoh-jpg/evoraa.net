# DIRECTIVE GLOBALE DE PRODUCTION
# KELIAA COUPLE™ — BILAN PREMIUM

## INSTRUCTION PRINCIPALE

Le document Premium actuel constitue la **base de référence du produit**.

Il ne faut PAS repartir de zéro.

Il ne faut PAS remplacer son architecture.

Il ne faut PAS transformer le Premium en Premium Plus.

Il faut conserver les grandes parties, le style rédactionnel, la logique, les exercices et le niveau de profondeur déjà présents dans le document Premium, puis appliquer les présentes règles à **l'ensemble du rapport** afin d'améliorer sa personnalisation, sa lisibilité, son rendu visuel et sa qualité d'expérience.

Le Premium Plus est un produit indépendant.

Le Premium doit rester un produit complet à part entière, mais il ne doit pas intégrer les fonctionnalités, protocoles et systèmes avancés réservés au Premium Plus.

---

# 1. LE DOCUMENT ACTUEL EST LE DOCUMENT MAÎTRE

Le contenu Premium actuellement fourni doit être considéré comme le **document maître**.

Conserver :

- son architecture générale ;
- ses grandes parties ;
- ses titres ;
- ses sous-titres ;
- ses analyses ;
- ses exercices ;
- ses recommandations ;
- son plan d'action ;
- son outil de suivi ;
- sa conclusion ;
- sa logique narrative.

Ne pas réécrire inutilement une partie qui fonctionne déjà.

Ne pas supprimer une partie simplement parce qu'une nouvelle directive est ajoutée.

Lorsque quelque chose existe déjà et répond au besoin, **conserver et améliorer uniquement si nécessaire**.

L'objectif est d'obtenir une version Premium enrichie et mieux produite, pas de créer un nouveau rapport.

---

# 2. LE CONTENU N'EST PAS IDENTIQUE POUR TOUS LES COUPLES

Le Premium est un moteur dynamique.

Le contenu présenté dans le document actuel sert de **structure et de modèle de production**.

Il ne doit jamais être considéré comme un texte qui doit être copié identiquement pour tous les utilisateurs.

Les utilisateurs fourniront des données différentes.

Le moteur devra donc exploiter les données réelles de chaque couple pour produire son rapport.

Deux couples ayant des profils différents doivent recevoir des rapports différents.

---

# 3. LES DONNÉES DÉTERMINENT LE CONTENU

Le moteur doit exploiter toutes les données disponibles et pertinentes dans le bilan.

Cela peut inclure :

- réponses individuelles ;
- scores ;
- écarts entre partenaires ;
- convergences ;
- profils ;
- besoins ;
- valeurs ;
- communication ;
- désaccords ;
- sécurité affective ;
- proximité ;
- finances ;
- projet de vie ;
- carrière ;
- familles ;
- frontières ;
- foi ;
- décisions ;
- rôles ;
- aspirations ;
- autres dimensions réellement mesurées.

Mais attention :

**Toutes les données ne doivent pas être utilisées dans tous les rapports.**

Le moteur doit sélectionner les informations pertinentes.

Si une dimension est très convergente et ne présente aucune difficulté particulière, son traitement peut être plus court.

Si une dimension présente un écart important, une tension potentielle ou une complémentarité intéressante, elle peut être davantage développée.

La profondeur du rapport doit donc être **adaptative**.

---

# 4. NE JAMAIS INVENTER DES INFORMATIONS

Le moteur ne doit jamais inventer un problème, une qualité, une difficulté ou une dynamique qui n'est pas soutenue par les données.

Il peut interpréter les résultats.

Il peut établir des liens entre plusieurs données.

Il peut formuler une hypothèse relationnelle cohérente.

Mais il ne doit jamais transformer une hypothèse en certitude.

Utiliser lorsque nécessaire :

« Vos réponses peuvent suggérer que... »

« Cette différence semble apparaître particulièrement lorsque... »

« Il pourrait être utile d'observer si... »

« Cette tendance peut parfois se manifester par... »

Le rapport ne doit jamais donner l'impression de poser un diagnostic psychologique ou médical.

---

# 5. LE RAPPORT DOIT RACONTER UNE HISTOIRE

Le Premium ne doit pas être une succession de résultats.

Chaque partie doit aider le couple à comprendre progressivement :

**Qui sommes-nous individuellement ?**

**Comment nos fonctionnements se rencontrent-ils ?**

**Qu'est-ce qui fonctionne entre nous ?**

**Qu'est-ce qui nous différencie ?**

**Qu'est-ce qui peut créer des incompréhensions ?**

**Comment ces différences peuvent-elles devenir des forces ?**

**Que pouvons-nous faire concrètement ?**

La lecture doit donner l'impression d'une véritable découverte progressive du couple.

---

# 6. LES ANALYSES DOIVENT ÊTRE INTERPRÉTÉES

Ne jamais se contenter de présenter un score.

Éviter :

> Communication : 75 %.

Puis passer immédiatement au sujet suivant.

Le score doit être interprété.

Expliquer :

- ce qu'il suggère ;
- comment il peut se manifester ;
- ce que cela signifie pour le couple ;
- ce qui fonctionne ;
- ce qui mérite éventuellement de l'attention.

Le résultat doit toujours être transformé en **compréhension concrète**.

---

# 7. CROISER LES DONNÉES

Le moteur doit rechercher les interactions entre les différentes dimensions.

Ne pas analyser uniquement :

« Daniel est comme ceci. »

Puis :

« Naomi est comme cela. »

Il faut également analyser :

> **« Lorsque Daniel et Naomi se rencontrent avec ces deux fonctionnements, voici ce qui peut se produire. »**

Rechercher notamment les croisements pertinents entre :

- personnalité ;
- communication ;
- désaccords ;
- sécurité ;
- proximité ;
- finances ;
- projet de vie ;
- carrière ;
- familles ;
- foi ;
- décisions ;
- rôles.

Tous les croisements ne sont pas obligatoires.

Le moteur doit sélectionner ceux qui ont une réelle signification pour le couple.

---

# 8. CHAQUE GRANDE PARTIE DOIT AVOIR DE VRAIS PARAGRAPHES

RÈGLE ABSOLUE :

Ne pas écrire une succession de phrases isolées.

Ne pas faire :

> Vous aimez communiquer.  
> Vous avez des valeurs communes.  
> Vous êtes différents sur l'argent.

Cela donne un rendu artificiel et pauvre.

Privilégier des paragraphes de **3 à 5 phrases**, généralement courts et lisibles.

Certains paragraphes peuvent être plus courts lorsqu'une phrase suffit réellement.

Certains peuvent être légèrement plus longs lorsqu'une explication le nécessite.

Mais le minimum de qualité est toujours :

**un véritable paragraphe explicatif.**

---

# 9. ALTERner LES FORMATS

Le rapport ne doit pas être composé uniquement de paragraphes.

Alterner intelligemment :

- paragraphes ;
- titres ;
- sous-titres ;
- listes à puces ;
- tableaux ;
- encadrés ;
- questions ;
- exercices ;
- cartes ;
- schémas ;
- synthèses ;
- espaces de réponse.

La mise en page doit donner du rythme.

Mais ne pas transformer chaque phrase en élément graphique.

---

# 10. LES SCHÉMAS DOIVENT ÊTRE VISUELS

Lorsqu'une partie explique un mécanisme, un cycle ou une relation entre plusieurs éléments, **ne pas simplement écrire le mécanisme en texte**.

Le traduire visuellement.

Par exemple :

**Déclencheur**

↓

**Réaction de Daniel**

↓

**Réaction de Naomi**

↓

**Conséquence**

↓

**Ce qui entretient le cycle**

↓

**Point d'intervention**

Ce contenu doit devenir un véritable schéma graphique.

Même principe pour :

- cycles relationnels ;
- processus ;
- interactions ;
- complémentarités ;
- matrices ;
- parcours ;
- relations entre deux profils ;
- évolution d'une situation.

Le visuel doit être utilisé lorsque cela améliore réellement la compréhension.

---

# 11. LES CARTES DOIVENT ÊTRE DE VRAIES CARTES

Lorsque le contenu se prête à une présentation sous forme de carte, créer une véritable carte visuelle.

Exemples :

### Carte des forces

Trois blocs mettant en évidence les principales ressources du couple.

### Carte des différences

Trois différences avec leur interprétation.

### Carte des points de vigilance

Deux ou trois points réellement importants.

### Carte des complémentarités

Les différences qui peuvent devenir des forces.

### Carte des priorités

Les trois sujets auxquels le couple devrait accorder son attention.

### Carte de première action

Une action simple à réaliser.

Ces cartes doivent pouvoir être consultées dans l'application et, lorsque pertinent, téléchargées ou imprimées.

---

# 12. LES EXERCICES DOIVENT ÊTRE PERSONNALISÉS

Les exercices déjà présents dans le Premium doivent être conservés.

Ils ne doivent pas être supprimés simplement pour faire de la place.

Mais leur sélection et leur formulation doivent être adaptées aux résultats du couple lorsque cela est pertinent.

Ne pas donner automatiquement tous les exercices à tous les couples.

Si les résultats montrent une difficulté particulière sur :

- communication ;
- finances ;
- projet ;
- famille ;
- proximité ;
- décisions ;

le moteur peut sélectionner l'exercice correspondant.

L'exercice doit avoir une raison d'être.

Il ne doit jamais être ajouté simplement pour augmenter le nombre de pages.

---

# 13. LES EXERCICES DOIVENT ÊTRE DE VRAIES FICHES

Lorsqu'une question demande une réponse personnelle, créer un véritable espace de réponse.

Ne pas placer une longue liste de questions compactées.

Exemple :

### QUESTION

**Qu'est-ce que tu aimerais que ton partenaire comprenne mieux chez toi ?**

[ESPACE DE RÉPONSE]

________________________________________________

________________________________________________

________________________________________________

Puis seulement ensuite passer à la question suivante.

Le document doit pouvoir être :

- imprimé ;
- rempli à la main ;
- rempli numériquement lorsque possible ;
- téléchargé.

---

# 14. LES EXERCICES PEUVENT ÊTRE VISUALISÉS

Lorsque cela est pertinent, transformer les exercices en :

- cartes ;
- fiches ;
- tableaux ;
- matrices ;
- roues ;
- grilles ;
- checklists ;
- espaces de réflexion.

L'objectif est de rendre l'exercice agréable à utiliser.

Mais ne pas surcharger.

Un exercice doit rester immédiatement compréhensible.

---

# 15. CHAQUE GRANDE PARTIE DOIT SE TERMINER PAR UNE CONCLUSION

Ne jamais terminer brutalement une partie après un exercice.

Après une grande analyse, prévoir une courte conclusion.

Cette conclusion doit expliquer :

1. Ce que le couple vient de découvrir.
2. Ce que cela signifie pour leur relation.
3. Ce qu'il faut retenir.
4. Ce qu'ils peuvent commencer à faire.

La conclusion doit généralement comporter **3 à 4 petits paragraphes**.

---

# 16. LES RECOMMANDATIONS DOIVENT ÊTRE CONCRÈTES

Éviter :

> « Vous devez mieux communiquer. »

Préférer :

> « Lorsque vous abordez une décision importante, essayez de distinguer le moment où vous cherchez à être compris du moment où vous cherchez réellement une solution. Cette distinction peut vous permettre de ne pas transformer une conversation importante en discussion immédiatement orientée vers la décision. »

Toujours expliquer :

**ce qui est observé → ce que cela peut produire → ce qui peut être essayé.**

---

# 17. LE RAPPORT DOIT RESTER A4

Le document final doit être conçu en **format A4**.

Mais il ne doit pas ressembler à un document administratif ou scolaire.

Il doit ressembler à un véritable rapport Premium KELIAA.

Le format A4 doit être utilisé pour permettre :

- une lecture confortable ;
- une impression facile ;
- un téléchargement simple ;
- une consultation sur écran ;
- une bonne intégration des exercices ;
- une bonne intégration des schémas et cartes.

---

# 18. LISIBILITÉ ABSOLUE

IMPORTANT :

Ne jamais réduire la taille du texte simplement pour faire tenir davantage de contenu sur une page.

La lisibilité est prioritaire.

Utiliser une taille de texte confortable.

La typographie peut être élégante, mais elle doit rester immédiatement lisible.

Éviter :

- caractères trop petits ;
- textes trop serrés ;
- interlignes insuffisants ;
- marges trop faibles ;
- paragraphes compacts ;
- tableaux illisibles.

Le rapport doit respirer.

---

# 19. NE PAS AVOIR PEUR DE PLUSIEURS PAGES

Si une analyse nécessite deux pages pour être correctement présentée, utiliser deux pages.

Ne pas compresser artificiellement le contenu.

Une page doit avoir suffisamment d'espace blanc pour permettre une lecture agréable.

Un rapport Premium n'est pas jugé sur le nombre maximal d'informations qu'on peut faire tenir sur une page.

Il est jugé sur :

**la qualité de l'information + la personnalisation + la lisibilité + l'expérience.**

---

# 20. IDENTITÉ VISUELLE KELIAA

Tout le rapport doit appartenir visuellement à KELIAA.

Les nouvelles sections, les cartes, les schémas et les exercices ne doivent jamais donner l'impression d'avoir été ajoutés depuis un autre produit.

Respecter :

- les couleurs KELIAA ;
- la typographie ;
- les formes ;
- les arrondis ;
- les espacements ;
- les principes visuels ;
- l'identité générale de l'application.

Le rapport doit donner l'impression d'être **une extension naturelle de KELIAA**.

---

# 21. VISUELS DANS TOUT LE RAPPORT

Les visuels ne sont pas réservés à la Carte relationnelle.

Tout le document doit être examiné afin d'identifier les endroits où un visuel peut améliorer la compréhension.

Par exemple :

### Profil individuel

→ jauges, indicateurs, cartes de caractéristiques.

### Rencontre des deux profils

→ schéma de convergence ou de complémentarité.

### Communication

→ schéma du fonctionnement de communication.

### Désaccords

→ cycle relationnel.

### Finances

→ tableau ou carte des différences.

### Projet de vie

→ ligne du temps.

### Carrière

→ matrice aspirations / contraintes.

### Besoins affectifs

→ carte des besoins de chacun.

### Familles

→ schéma de frontières du couple.

### Synthèse

→ Carte relationnelle.

Ne pas ajouter des visuels simplement pour décorer.

Chaque visuel doit avoir une fonction.

---

# 22. ANIMATIONS ET INTERACTIVITÉ

Dans la version application, utiliser lorsque pertinent :

- cartes interactives ;
- éléments dépliables ;
- animations légères ;
- graphiques ;
- transitions ;
- boutons ;
- fiches téléchargeables ;
- exercices interactifs ;
- espaces de réponse.

Mais l'animation ne doit jamais devenir une distraction.

L'expérience doit rester élégante et professionnelle.

---

# 23. TÉLÉCHARGEMENT

Le rapport doit permettre au couple de télécharger :

**le rapport complet ;**

**les fiches d'exercices ;**

**les cartes importantes ;**

**les éléments qu'il peut souhaiter conserver.**

Le bouton doit être clairement nommé :

**Télécharger**

ou

**Télécharger le rapport**

ou

**Télécharger cette fiche**

Ne jamais afficher :

**Partager le prompt**

ou toute formulation faisant référence au fonctionnement interne de l'IA.

L'utilisateur achète une expérience KELIAA, pas un prompt.

---

# 24. LE CONTENU INTERNE NE DOIT JAMAIS ÊTRE EXPOSÉ

Ne jamais afficher à l'utilisateur :

- prompts ;
- instructions du moteur ;
- règles de génération ;
- variables internes ;
- scores techniques non destinés à l'utilisateur ;
- logique de calcul ;
- termes techniques de programmation.

Tout cela reste dans le moteur.

L'utilisateur doit voir uniquement **le résultat final de son bilan**.

---

# 25. LA PERSONNALISATION DOIT ÊTRE VISIBLE

Le couple doit pouvoir sentir que le rapport a été construit pour lui.

La personnalisation doit apparaître dans :

- les analyses ;
- les exemples ;
- les recommandations ;
- les exercices ;
- les cartes ;
- les priorités ;
- les conclusions.

Éviter les phrases génériques qui pourraient être données à n'importe quel couple.

---

# 26. NE PAS FORCER UNE INFORMATION

Si les données ne permettent pas de développer une dimension, ne pas inventer.

Si une partie n'est pas particulièrement significative pour un couple, elle peut être plus courte.

Si une partie est extrêmement importante pour eux, elle peut être davantage développée.

Le rapport doit donc avoir une **structure commune**, mais un **contenu variable**.

---

# 27. LA CARTE RELATIONNELLE

La Carte relationnelle constitue la synthèse finale du Premium.

Elle doit exploiter les données du rapport.

Elle doit présenter :

### Ce qui vous unit

3 forces maximum.

### Ce qui vous différencie

3 différences maximum.

### Ce qui peut créer des tensions

2 ou 3 points maximum.

### Ce qui peut devenir une complémentarité

2 ou 3 éléments maximum.

### Ce que vous devez clarifier

3 priorités maximum.

### Votre dynamique en une phrase

Une phrase générée à partir de leurs résultats.

### Votre première action

Une action concrète et réaliste.

La Carte relationnelle doit être particulièrement visuelle et facilement conservable.

---

# 28. LE RAPPORT DOIT RESTER HUMAIN

Le texte doit être chaleureux, naturel et précis.

Éviter les formulations artificielles ou répétitives.

Éviter les phrases génériques du type :

« Votre couple est unique et chaque relation est différente. »

sauf lorsqu'elles apportent réellement quelque chose.

Privilégier des formulations qui parlent directement de ce que les résultats montrent.

Le texte doit donner l'impression qu'un professionnel a réellement étudié les réponses du couple.

---

# 29. NE PAS SURCHARGER LE PREMIUM

Le Premium doit être riche.

Mais riche ne signifie pas :

**toujours plus de pages.**

Riche signifie :

- plus de compréhension ;
- meilleure personnalisation ;
- meilleurs croisements ;
- meilleurs exemples ;
- meilleurs exercices ;
- meilleurs visuels ;
- meilleure lisibilité.

Ne pas ajouter des fonctionnalités ou des protocoles uniquement parce qu'ils pourraient sembler « premium ».

Tout ce qui relève d'un accompagnement approfondi, de protocoles avancés ou d'un système de transformation structuré reste réservé au Premium Plus.

---

# 30. DIFFÉRENCE AVEC LE PREMIUM PLUS

Le Premium doit répondre à :

> **« Qui sommes-nous en tant que couple, comment fonctionnons-nous ensemble et que pouvons-nous commencer à améliorer ? »**

Le Premium Plus répondra à une logique différente et beaucoup plus approfondie.

NE PAS importer dans le Premium :

- protocoles avancés ;
- transformation relationnelle complète ;
- systèmes complexes de suivi ;
- programmes 30/60/90 jours avancés ;
- bibliothèques massives d'exercices ;
- scénarios relationnels avancés ;
- systèmes de maintenance ;
- protocoles détaillés de réparation ;
- architecture complète d'accompagnement.

Le Premium doit rester **un bilan approfondi avec des outils concrets**.

---

# 31. CONTRÔLE QUALITÉ AVANT LIVRAISON

Avant de considérer un rapport Premium comme terminé, vérifier :

□ Le rapport utilise-t-il réellement les données du couple ?

□ Les deux partenaires sont-ils analysés individuellement puis ensemble ?

□ Les principales convergences sont-elles identifiées ?

□ Les principales différences sont-elles expliquées ?

□ Les croisements pertinents ont-ils été effectués ?

□ Les mécanismes relationnels importants sont-ils expliqués ?

□ Les exercices sont-ils réellement liés aux résultats ?

□ Les conclusions existent-elles après les grandes parties ?

□ Les paragraphes sont-ils suffisamment développés ?

□ Le texte est-il lisible ?

□ Les visuels sont-ils utilisés lorsqu'ils améliorent la compréhension ?

□ Les cycles et mécanismes sont-ils transformés en schémas ?

□ Les exercices sont-ils présentés comme de vraies fiches ?

□ Le rapport est-il réellement personnalisé ?

□ Le format A4 est-il respecté ?

□ La taille du texte est-elle confortable ?

□ Le document est-il suffisamment aéré ?

□ Les cartes sont-elles téléchargeables ?

□ Le rapport complet est-il téléchargeable ?

□ Aucun prompt ou élément interne n'est-il visible ?

□ Le document respecte-t-il l'identité KELIAA ?

□ Le résultat reste-t-il clairement distinct du Premium Plus ?

---

# 32. RÈGLE FINALE DE PRODUCTION

Ne considère jamais le contenu fourni comme un texte figé à reproduire.

Considère-le comme **le modèle éditorial et architectural du produit**.

Les données réelles du couple doivent déterminer ce qui est développé.

Les écarts déterminent les différences à expliquer.

Les convergences déterminent les forces à mettre en avant.

Les interactions entre données déterminent les dynamiques à expliquer.

Les dynamiques déterminent les schémas.

Les résultats déterminent les exercices.

Les priorités déterminent les recommandations.

Et toutes ces informations doivent être transformées en une expérience visuelle KELIAA cohérente, élégante, lisible, téléchargeable et imprimable.

## LE RÉSULTAT ATTENDU

Lorsque le couple termine son Premium, il doit pouvoir se dire :

> **« Ce rapport ne nous a pas simplement donné des résultats. Il nous a aidés à comprendre comment nous fonctionnons ensemble, ce qui fait notre force, ce qui peut nous mettre en difficulté et ce que nous pouvons commencer à faire différemment. »**

C'est cette expérience qui doit guider toute la production du **KELIAA COUPLE™ PREMIUM**.
