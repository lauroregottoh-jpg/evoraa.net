# 12. VOTRE RÈGLE DE PAUSE

Lorsque la tension dépasse un certain niveau, chacun peut demander une pause.

Mais cette pause doit respecter quatre conditions.

### Première condition

La personne explique qu'elle demande une pause pour réguler la situation, et non pour punir l'autre.

### Deuxième condition

Elle indique une durée approximative.

### Troisième condition

Elle indique qu'elle reviendra réellement vers le sujet.

### Quatrième condition

Le couple respecte le moment convenu pour reprendre la conversation.

Cette règle peut permettre à Marc de disposer de son espace sans laisser Élodie dans l'incertitude.

Ces deux phrases peuvent sembler simples.

Pourtant, elles peuvent modifier profondément votre dynamique.

Votre couple n'a pas besoin de devenir un couple sans conflits.

Il a besoin de devenir un couple qui sait **revenir l'un vers l'autre après un conflit.**

C'est cette capacité qui mérite aujourd'hui votre investissement.
