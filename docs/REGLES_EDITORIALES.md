# Règles éditoriales -- KELIAA

## Objectif

Les contenus affichés dans l'espace membre (Pensée du jour, Conseil,
Défi, Question, etc.) doivent donner l'impression d'avoir été rédigés
par un véritable conseiller conjugal, et non par une intelligence
artificielle.

Chaque contenu doit être utile, concret, naturel et applicable
immédiatement.

------------------------------------------------------------------------

# Ce qu'il faut faire

-   Écrire comme un coach qui accompagne de vrais couples.
-   Utiliser un français simple et naturel.
-   Partir de situations réelles que vivent les couples.
-   Donner un conseil pratique.
-   Faire réfléchir sans juger.
-   Être bienveillant.
-   Être concret.
-   Utiliser des exemples du quotidien.
-   Donner une action simple lorsque c'est pertinent.
-   Limiter les textes entre **60 et 180 mots**.

------------------------------------------------------------------------

# Ce qu'il faut éviter

Ne jamais écrire des phrases génériques comme :

-   « L'amour est... »
-   « Une relation heureuse... »
-   « Les couples heureux... »
-   « La communication est la clé... »
-   « L'amour triomphe toujours... »
-   « Il faut simplement communiquer. »

Éviter également :

-   les citations de développement personnel ;
-   les phrases qui sonnent comme Instagram ;
-   les phrases philosophiques ;
-   les généralités ;
-   les clichés ;
-   les formulations vagues ;
-   les conseils impossibles à appliquer.

------------------------------------------------------------------------

# Le ton recherché

Le lecteur doit avoir l'impression que quelqu'un lui parle
personnellement.

Préférer :

> « Si une discussion devient tendue, prenez quelques minutes avant de
> répondre. »

Plutôt que :

> « Une bonne communication favorise une relation harmonieuse. »

------------------------------------------------------------------------

# Toujours partir d'une situation réelle

Exemples :

-   une dispute ;
-   un silence qui dure ;
-   un oubli ;
-   la fatigue ;
-   les écrans ;
-   les finances ;
-   les enfants ;
-   la belle-famille ;
-   le manque de temps ;
-   les attentes ;
-   la jalousie ;
-   le pardon ;
-   les projets ;
-   les habitudes.

------------------------------------------------------------------------

# Les contenus doivent être variés

Ne pas produire uniquement des pensées.

Utiliser différentes catégories :

-   Pensée du jour
-   Conseil du coach
-   Défi du jour
-   Question de réflexion
-   Astuce communication
-   Erreur fréquente
-   Le saviez-vous ?
-   Verset expliqué
-   Préparation au mariage
-   Exercice de couple
-   Idée de discussion
-   Citation d'un spécialiste reconnu (occasionnellement)

------------------------------------------------------------------------

# Les défis

Les défis doivent être réalisables en moins de 15 minutes.

Exemples :

-   remercier son partenaire ;
-   poser une question sincère ;
-   prier ensemble ;
-   marcher ensemble ;
-   dîner sans téléphone.

------------------------------------------------------------------------

# Les questions

Les questions doivent inviter à réfléchir.

Ne jamais poser des questions vagues.

Préférer :

> « Quand avez-vous pris le temps d'écouter votre partenaire sans
> regarder votre téléphone ? »

Plutôt que :

> « Comment améliorer votre relation ? »

------------------------------------------------------------------------

# Les conseils

Les conseils doivent toujours être :

-   précis ;
-   applicables ;
-   réalistes ;
-   bienveillants.

Ils ne doivent jamais être moralisateurs.

------------------------------------------------------------------------

# Style

-   phrases courtes ;
-   vocabulaire simple ;
-   pas de jargon psychologique ;
-   pas de ton universitaire ;
-   pas de ton religieux excessif ;
-   pas de ton commercial ;
-   pas d'emojis ;
-   pas de hashtags.

------------------------------------------------------------------------

# Spiritualité

La foi fait partie de l'identité de KELIAA.

Cependant :

-   ne pas citer un verset dans chaque contenu ;
-   ne pas transformer chaque texte en prédication ;
-   intégrer les références bibliques uniquement lorsqu'elles apportent
    une réelle valeur.

------------------------------------------------------------------------

# Impression finale recherchée

À la lecture, l'utilisateur doit penser :

> « On dirait qu'un conseiller conjugal m'a écrit ce message. »

Il ne doit jamais penser :

> « Cette phrase a été générée par une IA. »

Avant de générer un contenu, vérifier systématiquement :

1.  Est-ce concret ?
2.  Est-ce crédible ?
3.  Est-ce applicable aujourd'hui ?
4.  Est-ce qu'un conseiller humain pourrait dire exactement cela ?
5.  Est-ce que cette phrase pourrait être publiée sur n'importe quelle
    page de citations ?

Si la réponse à la dernière question est **OUI**, réécrire complètement
le contenu.

------------------------------------------------------------------------

# Règle d'or

**Ne jamais chercher à "faire joli". Chercher à être utile.**

Chaque contenu doit aider l'utilisateur à mieux comprendre sa relation
ou à poser une action concrète aujourd'hui.

Si un texte est inspirant mais n'apporte aucun conseil pratique, il doit
être réécrit.
