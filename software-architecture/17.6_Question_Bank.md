# 17.6_Question_Bank.md

**Version:** 1.0 (MVP)

---

# Purpose

This document defines the structure of the master question bank used by KELIA.

For the MVP, the platform contains **34 validated questions** distributed across three assessments. The question bank is designed to be extensible without changing the matching engine.

---

# Assessment Distribution

| Assessment | Questions |
|------------|----------:|
| Personality | 12 |
| Spiritual Compatibility | 10 |
| Relationship Compatibility | 12 |
| **Total** | **34** |

---

# Question Metadata

Every question must include the following attributes:

- Question ID
- Assessment
- Dimension
- Display order
- Question text
- Response scale (1–5)
- Weight (default = 1)
- Status (Draft / Active / Archived)

---

# Response Scale

All questions use the same five-point Likert scale.

| Value | Meaning |
|------:|---------|
| 1 | Strongly disagree |
| 2 | Disagree |
| 3 | Neutral |
| 4 | Agree |
| 5 | Strongly agree |

A single response format improves usability and simplifies score calculation.

---

# Database Structure

Recommended fields:

- id
- assessment_id
- dimension
- question_text
- order_index
- weight
- is_reverse_scored
- status
- created_at
- updated_at

---

# Reverse Scoring

Some questions may be reverse scored to reduce response bias.

Example:

"I often avoid discussing problems."

Agreement with this statement decreases the communication score.

The MVP should support reverse scoring through a simple Boolean field.

---

# Versioning

Questions should never be deleted.

Instead:

- Archive outdated questions.
- Create new versions.
- Preserve historical responses for reporting.

---

# Administration

Administrators can:

- activate questions;
- archive questions;
- change display order;
- edit wording before publication.

Changes affect only future responses.

---

# Future Extensions (Excluded from MVP)

Future releases may introduce:

- adaptive question selection;
- multilingual question banks;
- category-specific questionnaires;
- AI-assisted question generation.
