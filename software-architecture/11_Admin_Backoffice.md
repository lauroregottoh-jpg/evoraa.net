# 11_Admin_Backoffice.md

**Version:** 1.0 (MVP)

---

# Purpose

This document defines the administration portal for KELIA MVP.

The back office enables platform administrators to monitor, moderate and manage the application without modifying source code.

---

# Administrator Roles

## Super Administrator

Can:

- Manage administrators
- Access all modules
- Configure platform settings

---

## Administrator

Can:

- Moderate users
- Manage reports
- Review subscriptions
- View analytics

---

# Dashboard

The dashboard displays:

- Total users
- New registrations
- Active users
- Premium subscriptions
- Revenue
- Pending reports
- Completed assessments
- Active conversations

---

# User Management

Administrators can:

- Search users
- View profiles
- Suspend accounts
- Restore accounts
- Delete accounts
- Verify user information

---

# Report Moderation

Administrators can:

- View reports
- Review evidence
- Warn users
- Suspend accounts
- Close reports

Report status:

- Pending
- Under Review
- Resolved
- Rejected

---

# Subscription Management

Administrators can:

- View subscriptions
- Activate subscriptions
- Extend subscriptions
- Cancel subscriptions
- View payment history

---

# Psychometric Tests

The back office allows administrators to:

- Create a test
- Activate or deactivate a test
- Create questions
- Modify questions
- Change question order

Assessment scoring rules remain protected and are managed separately.

---

# Notifications

Administrators can:

- Send platform announcements
- Notify selected users
- Broadcast maintenance messages

---

# Platform Settings

Manage:

- Application name
- Contact email
- Terms of service
- Privacy policy
- Support information

---

# Audit Log

Every administrative action is recorded with:

- Administrator ID
- Action
- Target resource
- Timestamp

Audit logs cannot be modified.

---

# Security

- Administrator authentication required
- Role-based permissions
- HTTPS only
- Server-side authorization
- Audit logging enabled

---

# Out of Scope (MVP)

- Advanced analytics
- Marketing automation
- A/B testing
- CRM integration
- AI moderation
