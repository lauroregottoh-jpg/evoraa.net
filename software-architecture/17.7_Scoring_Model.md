# KELIAA — Modèle de scoring

**Version :** 2.0
**Dernière mise à jour :** 30 juillet 2026

## Objectif

Transformer les réponses des cinq piliers en dimensions comparables, puis produire un score de compatibilité explicable.

## Score d’un pilier

1. Appliquer la valeur de chaque réponse.
2. Inverser la valeur si la question est marquée `reverse`.
3. Regrouper par dimension.
4. Normaliser les dimensions sur une échelle de 0 à 100.
5. Conserver le score du pilier et ses dimensions.

## Comparaison de deux membres

Le moteur compare uniquement les piliers et dimensions disponibles chez les deux membres.

Pour une dimension :

`alignement = 100 - abs(scoreA - scoreB)`

Le score psychométrique consolide les alignements disponibles et mesure :

- le score moyen ;
- le ratio de dimensions alignées ;
- le nombre de piliers communs.

## Fusion avec le profil

Le score de profil tient compte de :

- dénomination ;
- localisation ;
- âge ;
- fréquence de pratique ;
- vision du mariage ;
- projet familial ;
- style de communication.

Lorsque des piliers communs existent :

`poids_psy = min(0,85 ; 0,40 + piliers_communs × 0,09)`

Le résultat fusionne score de profil et score psychométrique, puis applique des plafonds de confiance liés à la couverture.

Sans données psychométriques communes, le score est plafonné à 72.

## Interprétation

- 90–100 : excellent.
- 75–89 : élevé.
- 60–74 : modéré.
- inférieur à 60 : faible.

Ces niveaux sont informatifs et ne prédisent pas la réussite d’une relation.

## Explicabilité

Le membre reçoit des raisons concrètes, par exemple :

- pourcentage de dimensions alignées ;
- piliers communs ;
- foi ou pratique proche ;
- vision du mariage ;
- projet de foyer ;
- communication ;
- proximité géographique.

Les scores bruts détaillés de l’autre membre ne sont pas révélés.

## Gouvernance

Le modèle doit rester :

- explicable ;
- reproductible ;
- versionné ;
- testé ;
- non discriminatoire ;
- révisable par l’équipe produit.

Les changements de formule doivent être accompagnés de tests de non-régression et d’une mise à jour de `08_Matching_Engine.md`.
