# KELLIA — Architecture des questionnaires

**Version :** 2.0
**Dernière mise à jour :** 30 juillet 2026
**Références :** `src/lib/assessments/questionBank.ts`, `src/lib/assessments/constants.ts`

## Piliers

Ordre officiel :

1. `personality` — Personnalité et stress
2. `spiritual` — Foi et vie spirituelle
3. `relationship` — Relation et communication
4. `couple_life` — Vie de couple
5. `finances` — Finances et projet de foyer

## Format

- Questions de scénario ou échelle de Likert.
- Options explicites avec valeur numérique.
- Certaines questions peuvent être inversées.
- Une dimension métier est associée à chaque question.

## Parcours

1. Le membre ouvre le hub `/assessments`.
2. Il sélectionne un pilier disponible.
3. Il répond aux scénarios avec progression visible.
4. Les réponses sont enregistrées.
5. Le résultat du pilier est normalisé.
6. Les dimensions sont consolidées dans le profil psychométrique.
7. Le moteur de matching exploite les piliers communs.

## Données

Le profil consolidé peut contenir :

- score par pilier ;
- dimensions par pilier ;
- nombre de piliers complétés ;
- date de mise à jour.

Les réponses détaillées et résultats restent liés au membre et protégés par RLS.

## Reprise

Un questionnaire validé peut être mis à jour après **60 jours**.

## UX

- Mobile-first.
- Progression visible.
- Aucun jugement « bonne/mauvaise réponse ».
- Explication de l’utilité des questions.
- Reprise sécurisée en cas d’interruption.
- Résultats accompagnés d’axes de croissance.

## Administration

La banque active est actuellement versionnée dans le code et les migrations. Toute modification doit préserver les anciennes réponses et documenter la version du modèle.
