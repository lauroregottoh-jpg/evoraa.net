# 17.2_Test_Architecture.md

**Version:** 1.0 (MVP)

---

# Purpose

This document defines the technical architecture of the assessment system for the KELIA MVP.

The goal is to provide a fast, consistent and scalable assessment experience.

---

# Assessment Flow

Every new member follows the same sequence:

1. Account creation
2. Profile completion
3. Personality Assessment
4. Spiritual Compatibility Assessment
5. Relationship Compatibility Assessment
6. Compatibility score generation
7. Access to suggested matches

Assessments are mandatory before matching begins.

---

# Assessment Overview

| Assessment | Questions | Estimated Time |
|------------|----------:|---------------:|
| Personality | 12 | 3 min |
| Spiritual Compatibility | 10 | 2–3 min |
| Relationship Compatibility | 12 | 3–4 min |

**Total:** 34 questions in approximately 8–10 minutes.

---

# Question Format

For the MVP, every question uses the same 5-point Likert scale:

1. Strongly disagree
2. Disagree
3. Neutral
4. Agree
5. Strongly agree

Using one response format simplifies scoring and improves the user experience.

---

# Navigation Rules

- One question displayed at a time.
- Progress bar always visible.
- Previous question allowed.
- Questions cannot be skipped.
- Automatic save after each answer.

---

# Scoring Process

Each answer receives a numerical value.

At the end of an assessment:

1. Raw score is calculated.
2. Score is normalized (0–100).
3. Dominant profile is determined.
4. Structured result is saved for the matching engine.

---

# Stored Data

For each assessment, store:

- Assessment ID
- User ID
- Question ID
- Selected answer
- Timestamp
- Normalized score
- Dominant profile

---

# Completion Rules

A user is considered "Assessment Complete" only when:

- All 34 questions have been answered.
- Scores have been calculated successfully.
- Results have been stored.

Only then is the matching engine activated.

---

# MVP Design Principles

- Fast to complete
- Easy to understand
- Minimal cognitive load
- Mobile-first
- Easy to extend in future versions

---

# Future Extensions (Excluded from MVP)

- Adaptive questioning
- Dynamic branching
- AI-generated follow-up questions
- Timed responses
- Premium deep-dive assessments
