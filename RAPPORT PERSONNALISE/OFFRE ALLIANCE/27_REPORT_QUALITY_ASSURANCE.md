# KELIAA ALLIANCE
## Contrôle Qualité du Rapport Personnalisé

**Version :** 1.0

---

# OBJECTIF

Ce document définit les règles de contrôle qualité du Rapport Personnalisé Alliance.

Avant qu'un rapport soit affiché au membre ou exporté en PDF, LIA doit vérifier qu'il respecte les standards de qualité de KELIAA.

Un rapport ne doit jamais être publié sans validation.

---

# PHILOSOPHIE

Un bon rapport ne se limite pas à être exact.

Il doit être :

- utile ;
- cohérent ;
- agréable à lire ;
- personnalisé ;
- actionnable.

Le membre doit repartir avec une meilleure compréhension de lui-même et savoir quelle est sa prochaine étape.

---

# CONTRÔLE N°1
## Vérification des données

Avant toute génération, vérifier :

- les informations du membre sont présentes ;
- les évaluations réalisées sont correctement identifiées ;
- les évaluations non réalisées sont correctement identifiées ;
- les scores sont disponibles ;
- les données ne sont pas corrompues.

En cas d'erreur :

Le rapport n'est pas généré.

---

# CONTRÔLE N°2
## Vérification de la structure

Le rapport doit contenir obligatoirement :

- couverture ;
- résumé personnalisé ;
- portrait relationnel ;
- forces ;
- axes de progression ;
- analyses disponibles ;
- évaluations à débloquer ;
- prochaines étapes ;
- progression ;
- conclusion.

Aucune section obligatoire ne peut être absente.

---

# CONTRÔLE N°3
## Vérification des analyses

Chaque analyse doit contenir :

- une explication ;
- au moins un point fort ;
- au moins un conseil pratique.

Une analyse ne doit jamais se limiter à un score.

---

# CONTRÔLE N°4
## Vérification des conseils

Les conseils doivent être :

- concrets ;
- réalisables ;
- compréhensibles.

À éviter :

- conseils vagues ;
- conseils impossibles à appliquer ;
- conseils culpabilisants.

---

# CONTRÔLE N°5
## Vérification des recommandations

Ne recommander que des ressources disponibles.

Aujourd'hui, les recommandations autorisées sont :

- approfondir une thématique ;
- réserver une séance de coaching ;
- réaliser une nouvelle évaluation.

Ne jamais recommander :

- un module inexistant ;
- une formation inexistante ;
- une ressource indisponible.

---

# CONTRÔLE N°6
## Vérification des évaluations manquantes

Chaque évaluation non réalisée doit apparaître dans la section :

**Analyses à débloquer**

Chaque carte doit contenir :

- le titre ;
- les bénéfices ;
- la durée ;
- le bouton d'action.

---

# CONTRÔLE N°7
## Vérification du ton

Le rapport doit rester :

- positif ;
- encourageant ;
- objectif ;
- respectueux.

Ne jamais utiliser :

- des formulations alarmantes ;
- des jugements ;
- des affirmations définitives.

---

# CONTRÔLE N°8
## Vérification des répétitions

Éviter de répéter plusieurs fois :

- les mêmes conseils ;
- les mêmes formulations ;
- les mêmes qualités.

Chaque section doit apporter une nouvelle information.

---

# CONTRÔLE N°9
## Vérification de la personnalisation

Le rapport doit donner l'impression d'avoir été écrit spécialement pour le membre.

Les sections doivent être cohérentes entre elles.

Aucune contradiction ne doit apparaître.

---

# CONTRÔLE N°10
## Vérification du PDF

Avant l'export :

- toutes les cartes sont visibles ;
- aucun texte n'est tronqué ;
- les titres sont correctement affichés ;
- la pagination est correcte ;
- les illustrations sont chargées.

---

# CHECKLIST DE VALIDATION

Avant publication, LIA valide automatiquement :

☐ Les données sont complètes.

☐ Les analyses sont cohérentes.

☐ Les conseils sont utiles.

☐ Les recommandations sont disponibles.

☐ Les évaluations manquantes sont affichées.

☐ Le rapport est fluide.

☐ Le ton est bienveillant.

☐ Le PDF est conforme.

Si une case n'est pas validée, le rapport doit être régénéré.

---

# CRITÈRES DE RÉUSSITE

Le rapport est considéré comme réussi si le membre peut répondre "oui" aux questions suivantes :

- Je me reconnais dans cette analyse.
- J'ai compris mes principales forces.
- Je sais quels domaines je dois améliorer.
- Je sais quelle est ma prochaine étape.
- J'ai envie de poursuivre mon parcours sur KELIAA.

---

# PRINCIPE FONDAMENTAL

Le Rapport Personnalisé Alliance représente la qualité de KELIAA.

Chaque rapport doit inspirer confiance, être facile à comprendre et apporter une réelle valeur au membre.

La qualité n'est pas une étape finale.

Elle fait partie intégrante du processus de génération du rapport.
