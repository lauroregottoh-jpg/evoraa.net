# ALLIANCE PERSONALIZED REPORT™
## Règles de Génération du Rapport

**Version :** 1.0

---

# Objectif

Ce document définit les règles métier utilisées pour construire automatiquement le Rapport Personnalisé Alliance.

Le rôle de LIA n'est pas d'interpréter librement les résultats.

Son rôle est de :

1. Lire les résultats des évaluations.
2. Appliquer les règles définies dans ce document.
3. Sélectionner les contenus appropriés dans la bibliothèque.
4. Assembler un rapport fluide et personnalisé.

Toutes les décisions suivent les règles ci-dessous.

---

# Principe 1

Les analyses sont construites à partir des données disponibles.

Aucune analyse ne peut être inventée.

Si une donnée est absente :

- l'analyse est reportée ;
- la section reste visible ;
- une invitation à compléter le test est affichée.

---

# Principe 2

Le rapport privilégie les éléments les plus importants.

Toutes les informations ne sont pas affichées.

Le rapport met en avant :

- les principales forces ;
- les principaux points de vigilance ;
- les priorités de progression.

Le rapport évite de surcharger le membre.

---

# Principe 3

Hiérarchisation des résultats

Les analyses sont classées selon leur importance.

Priorité très élevée

- risques majeurs
- incohérences importantes
- forces exceptionnelles

Priorité élevée

- compétences relationnelles
- communication
- gestion émotionnelle

Priorité normale

- préférences
- habitudes
- nuances

Les éléments les plus importants apparaissent en premier.

---

# Principe 4

Une même information ne doit jamais être répétée.

Si une idée est déjà développée dans une section :

- elle est simplement rappelée ailleurs ;
- elle n'est pas réécrite entièrement.

Le rapport doit rester agréable à lire.

---

# Principe 5

Construction du portrait

Le portrait relationnel est construit à partir de plusieurs évaluations.

Il ne dépend jamais d'un seul test.

Le portrait combine :

- personnalité
- communication
- intelligence émotionnelle
- valeurs
- spiritualité
- projet de vie

Plus le nombre de tests est élevé, plus le portrait devient précis.

---

# Principe 6

Sélection des forces

Le rapport affiche uniquement les forces les plus significatives.

Nombre maximum :

5

Une force est retenue lorsqu'elle :

- possède un score élevé ;
- est confirmée par plusieurs évaluations ;
- apporte une réelle valeur dans une relation.

---

# Principe 7

Sélection des points de vigilance

Le rapport affiche uniquement les axes de progression les plus utiles.

Nombre maximum :

5

Les points de vigilance sont choisis selon :

- leur impact potentiel ;
- leur fréquence ;
- leur influence sur la qualité d'une relation.

Le rapport ne doit jamais donner l'impression que le membre accumule les défauts.

---

# Principe 8

Priorités de progression

À partir des résultats, le rapport construit automatiquement un plan d'action.

Les priorités sont classées selon :

1. impact sur la relation ;
2. facilité de progression ;
3. urgence.

Maximum :

5 priorités.

---

# Principe 9

Gestion des données manquantes

Lorsqu'un test n'a pas été réalisé :

La section correspondante reste présente.

Elle contient :

- une explication ;
- les bénéfices de cette analyse ;
- un bouton invitant à réaliser le test.

Exemple :

🔒 Cette analyse sera disponible après avoir complété le test "Vision du mariage".

---

# Principe 10

Progression du rapport

Chaque nouveau test peut :

- compléter une analyse existante ;
- modifier une conclusion ;
- ajouter une nouvelle section ;
- mettre à jour les recommandations ;
- enrichir le portrait relationnel.

Le rapport est toujours régénéré dans sa globalité afin de conserver sa cohérence.

---

# Principe 11

Personnalisation des recommandations

Les recommandations sont choisies en fonction :

- des forces ;
- des axes de progression ;
- des évaluations disponibles ;
- du parcours déjà réalisé par le membre.

Les recommandations peuvent inclure :

- modules Alliance ;
- exercices ;
- défis ;
- lectures ;
- articles ;
- vidéos ;
- podcasts.

Les recommandations sont toujours personnalisées.

---

# Principe 12

Ton du rapport

Toutes les analyses doivent respecter les règles suivantes :

- être bienveillantes ;
- être encourageantes ;
- être concrètes ;
- être équilibrées ;
- être compréhensibles.

Le rapport ne doit jamais :

- faire peur ;
- culpabiliser ;
- juger ;
- diagnostiquer.

---

# Principe 13

Qualité éditoriale

Chaque section doit répondre à trois questions :

1. Qu'observons-nous ?
2. Pourquoi est-ce important ?
3. Que pouvez-vous faire maintenant ?

Si une analyse ne répond pas à ces trois questions, elle est incomplète.

---

# Principe 14

Évolution continue

Le Rapport Personnalisé Alliance n'est jamais considéré comme définitif.

Chaque nouvelle évaluation enrichit la compréhension du membre.

L'objectif est que le rapport accompagne la personne tout au long de son parcours de préparation au mariage.

---

# Règle fondamentale

Le Rapport Personnalisé Alliance ne se contente pas de décrire la personne.

Il doit toujours transformer les résultats des évaluations en une meilleure connaissance de soi, en pistes de progression concrètes et en recommandations personnalisées.

Chaque page du rapport doit aider le membre à devenir une meilleure version de lui-même avant de construire une relation durable.
