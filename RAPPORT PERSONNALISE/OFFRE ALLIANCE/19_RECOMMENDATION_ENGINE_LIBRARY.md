# ALLIANCE PERSONALIZED REPORT™
## Bibliothèque – Moteur de Recommandations

**Version :** 1.0

---

# Objectif

Cette bibliothèque rassemble toutes les recommandations pouvant être proposées dans le Rapport Personnalisé Alliance.

Son objectif est de transformer chaque analyse en une prochaine étape concrète.

Le rapport ne doit jamais laisser le membre avec un simple constat.

Chaque analyse doit conduire vers une ressource, une action ou un parcours de progression adapté à son profil.

---

# Définition

Une recommandation est une action personnalisée proposée au membre afin de :

- renforcer une compétence ;
- corriger une faiblesse ;
- développer une qualité ;
- approfondir un domaine ;
- poursuivre son évolution.

Toutes les recommandations sont générées automatiquement à partir des résultats des évaluations.

---

# Les catégories de recommandations

---

## 1. Modules Alliance

Le moteur recommande les modules de formation les plus adaptés.

Exemples :

- Communication dans le couple
- Gestion des conflits
- Intelligence émotionnelle
- Vision du mariage
- Finances du foyer
- Leadership conjugal
- Préparation au mariage

---

## 2. Exercices pratiques

Le moteur propose des exercices personnalisés.

Exemples :

- exercice d'écoute active
- journal émotionnel
- défi gratitude
- exercice de communication
- réflexion guidée
- planification de projet de vie

---

## 3. Défis Alliance

Défis courts permettant de créer une nouvelle habitude.

Exemples :

- Défi 7 jours d'écoute
- Défi pardon
- Défi communication
- Défi prière
- Défi gratitude
- Défi maîtrise émotionnelle

---

## 4. Articles

Sélection d'articles correspondant au profil.

Les articles doivent approfondir les sujets révélés par le rapport.

---

## 5. Podcasts

Le moteur recommande des épisodes ciblés.

La recommandation dépend :

- du profil ;
- des besoins ;
- du niveau de progression.

---

## 6. Vidéos

Sélection de vidéos adaptées.

Exemples :

- enseignements
- conférences
- capsules pratiques

---

## 7. Livres

Le moteur peut recommander des lectures.

Les livres sont sélectionnés selon :

- le domaine concerné ;
- le niveau du membre ;
- les objectifs du plan d'action.

---

## 8. Versets bibliques

Lorsque cela est pertinent.

Les versets sont utilisés :

- pour encourager ;
- pour inspirer ;
- pour approfondir la réflexion.

Ils ne sont jamais utilisés pour culpabiliser.

---

## 9. Prières

Le moteur peut proposer :

- une prière personnelle ;
- une prière de croissance ;
- une prière de préparation au mariage.

Les prières sont adaptées au contexte.

---

## 10. Accompagnement

Lorsque plusieurs dimensions nécessitent un travail important, le moteur peut recommander :

- coaching individuel ;
- préparation au mariage ;
- parcours Premium ;
- accompagnement spécifique.

---

# Les règles de recommandation

Le moteur prend en compte :

- les résultats des évaluations ;
- les priorités du rapport ;
- les ressources déjà consultées ;
- les modules déjà terminés ;
- les recommandations précédentes ;
- la progression du membre.

Les recommandations évoluent automatiquement.

---

# Les niveaux de recommandation

Chaque recommandation possède un niveau.

## Immédiate

À réaliser aujourd'hui.

---

## Court terme

Dans les prochaines semaines.

---

## Moyen terme

Après consolidation des premières compétences.

---

## Long terme

Pour poursuivre la croissance personnelle.

---

# Nombre de recommandations

Le rapport ne doit jamais surcharger le membre.

Par défaut :

- 3 recommandations prioritaires
- 5 recommandations complémentaires
- 10 ressources maximum

La qualité est privilégiée à la quantité.

---

# Les domaines concernés

Le moteur peut recommander des ressources pour :

- personnalité relationnelle ;
- communication ;
- gestion des conflits ;
- intelligence émotionnelle ;
- valeurs ;
- spiritualité ;
- vision du mariage ;
- projet de vie ;
- finances ;
- famille.

---

# Personnalisation

Chaque recommandation doit tenir compte :

- des points forts ;
- des axes de progression ;
- des centres d'intérêt ;
- des évaluations disponibles ;
- du parcours déjà effectué.

Deux membres ne doivent jamais recevoir exactement la même liste de recommandations.

---

# Questions auxquelles cette bibliothèque répond

Le Rapport Personnalisé doit répondre notamment aux questions suivantes :

- Quelle est la prochaine étape de mon parcours ?
- Quel module dois-je suivre en priorité ?
- Quel exercice m'aidera le plus aujourd'hui ?
- Quelles ressources correspondent à mon profil ?
- Comment continuer à progresser après la lecture du rapport ?

---

# Objectif du chapitre "Vos recommandations"

À la fin de cette section, le membre doit repartir avec une sélection de ressources qui répond directement à ses besoins actuels.

Les recommandations doivent être :

- pertinentes ;
- personnalisées ;
- progressives ;
- immédiatement utiles.

Cette section constitue le pont entre le Rapport Personnalisé Alliance et l'ensemble de l'écosystème Alliance.

---

# Évolutivité

Le moteur de recommandations évolue automatiquement.

Chaque nouveau module, chaque nouvelle vidéo, chaque nouveau podcast ou chaque nouveau parcours pourra être ajouté sans modifier la structure de cette bibliothèque.

Les recommandations deviendront ainsi de plus en plus précises au fil du développement de la plateforme.

---

# Principe fondamental

Le Rapport Personnalisé Alliance ne s'arrête pas à l'analyse.

Il ouvre un chemin de progression.

Chaque recommandation doit rapprocher le membre de son objectif : devenir une personne émotionnellement mature, spirituellement solide et pleinement préparée à construire un mariage durable selon les valeurs de KELIAA Alliance.
