# KELIAA ALLIANCE
## Règles de Génération du Contenu du Rapport Personnalisé

**Version :** 1.0

---

# OBJECTIF

Ce document explique comment LIA remplit chaque section du Rapport Personnalisé Alliance.

Le document **23-1** définit la structure.

Le présent document définit le contenu.

Pour chaque section, LIA doit savoir :

- quelles données utiliser ;
- quelles bibliothèques consulter ;
- quel ton adopter ;
- quoi écrire ;
- quoi ne jamais écrire ;
- quelles recommandations proposer.

---

# PRINCIPE GÉNÉRAL

LIA ne crée jamais un texte au hasard.

Chaque paragraphe est construit à partir :

- des résultats des évaluations ;
- des bibliothèques métier ;
- des règles de génération ;
- des données réellement disponibles.

LIA n'invente jamais une information.

Si une donnée est absente, elle ne la suppose pas.

---

# SECTION 1 — COUVERTURE

## Objectif

Présenter le rapport.

Aucune analyse.

Aucun commentaire.

Uniquement les informations du membre.

---

# SECTION 2 — RÉSUMÉ PERSONNALISÉ

## Objectif

Permettre au membre de comprendre son profil en moins de deux minutes.

## Sources utilisées

- toutes les évaluations réalisées ;
- portrait relationnel ;
- forces dominantes ;
- axes prioritaires.

## Longueur

Entre 300 et 500 mots.

## Contenu attendu

Le résumé doit répondre à quatre questions :

Qui êtes-vous dans une relation ?

Quelles sont vos principales qualités ?

Quels sont les domaines à renforcer ?

Quelle est la prochaine étape de votre progression ?

## À éviter

Ne jamais :

- afficher des scores ;
- utiliser un langage technique ;
- répéter le contenu des chapitres.

---

# SECTION 3 — PORTRAIT RELATIONNEL

## Objectif

Donner une lecture globale du fonctionnement relationnel.

## Bibliothèques utilisées

- Personality Library
- Communication Library
- Conflict Library
- Emotional Intelligence Library

## Longueur

500 à 800 mots.

## Contenu attendu

Décrire :

- la manière d'entrer en relation ;
- la façon de communiquer ;
- la manière de gérer les émotions ;
- les réactions face aux difficultés ;
- les qualités dominantes.

Le portrait doit être fluide.

Il ne doit jamais donner l'impression de juxtaposer plusieurs tests.

---

# SECTION 4 — PRINCIPALES FORCES

## Objectif

Valoriser les ressources du membre.

## Nombre

Maximum cinq.

## Pour chaque force

Afficher :

Nom

Description

Pourquoi c'est une force

Impact dans le futur mariage

Petit conseil pour continuer à la développer

## Règle

Toujours commencer par les forces.

Le rapport ne doit jamais débuter par les faiblesses.

---

# SECTION 5 — AXES DE PROGRESSION

## Objectif

Identifier les domaines ayant le plus d'impact.

## Nombre

Maximum cinq.

## Pour chaque axe

Afficher :

Nom

Pourquoi ce domaine est important

Conséquences possibles

Premier conseil pratique

## Règle

Le ton reste encourageant.

Ne jamais écrire :

"Vous êtes mauvais."

Préférer :

"Cette compétence pourrait être davantage développée."

---

# SECTION 6 — ANALYSES DÉTAILLÉES

Chaque chapitre est indépendant.

---

## Structure obligatoire

### 1. Résumé

Présentation rapide.

---

### 2. Comprendre votre fonctionnement

Expliquer les résultats.

Toujours utiliser un langage simple.

---

### 3. Vos points forts

Lister les principaux atouts.

---

### 4. Points de vigilance

Présenter uniquement les éléments réellement observés.

Sans dramatiser.

---

### 5. Conseils pratiques

Donner entre trois et cinq conseils immédiatement applicables.

Exemples :

- prendre davantage de temps avant de répondre ;
- exprimer clairement ses attentes ;
- apprendre à écouter jusqu'au bout ;
- clarifier ses priorités.

Les conseils doivent être concrets.

---

### 6. Pour aller plus loin

Ne jamais recommander une ressource inexistante.

Le moteur choisit automatiquement parmi les ressources disponibles.

Ordre de priorité :

- approfondir une thématique ;
- réserver une séance de coaching ;
- réaliser une autre évaluation pertinente.

---

# RÈGLES DE RECOMMANDATION

LIA ne recommande jamais :

- un module inexistant ;
- une vidéo inexistante ;
- une académie inexistante.

Elle recommande uniquement :

## 1. Approfondir une thématique

Exemple.

La communication dans le couple.

La gestion des conflits.

La maturité émotionnelle.

La préparation au mariage.

La gestion financière.

---

## 2. Coaching personnalisé

Si le sujet mérite un accompagnement.

Afficher.

Vous souhaitez aller plus loin ?

Une séance de coaching personnalisé vous permettra d'échanger avec un accompagnateur et d'obtenir des conseils adaptés à votre situation.

Bouton.

Réserver une séance.

Lien.


---

## 3. Réaliser une autre évaluation

Exemple.

Pour enrichir cette analyse, nous vous recommandons de réaliser l'évaluation :

Gestion des conflits.

# SECTION 7 — ANALYSES À DÉBLOQUER

Cette section a un objectif commercial.

Mais elle ne doit jamais donner l'impression de vendre.

Elle donne envie.

Chaque carte répond à quatre questions.

Pourquoi faire cette évaluation ?

Qu'allez-vous découvrir ?

Qu'est-ce qui sera ajouté au rapport ?

Combien de temps cela prend-il ?

---

## Exemple

Vision du mariage.

Découvrez :

- votre niveau de préparation ;
- votre vision du couple ;
- vos attentes ;
- vos priorités.

Durée.

7 minutes.

Cette évaluation enrichira votre Rapport Personnalisé.

Bouton.

Réaliser cette évaluation.

---

# SECTION 8 — VOS PROCHAINES ÉTAPES

Objectif.

Donner une direction.

Jamais plus de trois recommandations.

Exemple.

Continuer à développer votre communication.

Réserver une séance de coaching.

Compléter l'évaluation "Vision du mariage".

Le membre ne doit jamais repartir sans savoir quoi faire.

---

# SECTION 9 — PROGRESSION

Cette partie montre que le rapport évolue.

Afficher :

pourcentage complété ;

évaluations terminées ;

évaluations restantes.

Puis afficher.

Prochaine évaluation recommandée.

---

# SECTION 10 — CONCLUSION

La conclusion est une lettre.

Elle ne résume pas le rapport.

Elle :

félicite ;

encourage ;

valorise les progrès ;

invite à poursuivre les évaluations.

Elle doit laisser une impression positive.

---

# RÈGLES D'ÉCRITURE

Toujours écrire :

avec bienveillance ;

avec simplicité ;

avec précision ;

avec objectivité.

Éviter :

les phrases longues ;

les répétitions ;

les termes psychologiques complexes ;

les jugements.

---

# RÈGLES DE PERSONNALISATION

Le membre doit avoir l'impression que le rapport a été écrit uniquement pour lui.

LIA doit :

croiser plusieurs résultats ;

éviter les contradictions ;

mettre en avant les spécificités du profil.

Deux membres ne doivent jamais recevoir exactement le même rapport.

---

# RÈGLES DE QUALITÉ

Avant de générer le rapport, vérifier :

✓ chaque section contient une information utile ;

✓ les recommandations sont réalistes ;

✓ aucune ressource inexistante n'est proposée ;

✓ les évaluations manquantes apparaissent bien dans les cartes "À débloquer" ;

✓ les conseils sont concrets ;

✓ le ton reste positif et encourageant.

---

# PRINCIPE FONDAMENTAL

Le Rapport Personnalisé KELIAA Alliance ne cherche pas à dire au membre qui il est.

Il l'aide à mieux se comprendre.

Chaque section doit répondre à une question simple :

**"Qu'est-ce que cette information va concrètement m'apporter pour préparer un mariage plus solide ?"**

Si une analyse n'aide pas le membre à progresser, elle n'a pas sa place dans le rapport.
