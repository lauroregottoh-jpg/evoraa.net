# 06_REPORT_GENERATION_PIPELINE.md

# ALLIANCE PERSONALIZED REPORT™
## Pipeline de Génération du Rapport

**Version :** 1.0

---

# Objectif

Ce document décrit le processus complet permettant à LIA de générer un Rapport Personnalisé Alliance.

Le rapport n'est jamais écrit au hasard.

Chaque génération suit exactement les mêmes étapes afin de garantir :

- une qualité constante ;
- une personnalisation élevée ;
- une cohérence éditoriale ;
- une évolution automatique du rapport.

---

# Vue d'ensemble

Chaque génération suit le pipeline suivant :

```
Résultats des tests

↓

Validation des données

↓

Calcul des indicateurs

↓

Identification des points forts

↓

Identification des points de vigilance

↓

Sélection des contenus

↓

Construction des chapitres

↓

Personnalisation

↓

Vérification qualité

↓

Rapport final
```

---

# ÉTAPE 1
## Collecter les données

Récupérer :

- les tests complétés ;
- les scores calculés ;
- les dimensions disponibles ;
- les ressources déjà consultées ;
- les modules déjà suivis.

Ne jamais utiliser une donnée non validée.

---

# ÉTAPE 2
## Vérifier les données

Identifier :

- les évaluations complètes ;
- les évaluations incomplètes ;
- les évaluations absentes.

Créer la liste des analyses pouvant réellement être générées.

---

# ÉTAPE 3
## Calculer les indicateurs

Calculer automatiquement :

- indice global de préparation relationnelle ;
- nombre de forces identifiées ;
- nombre de priorités ;
- progression du profil ;
- niveau de complétude du rapport.

Ces indicateurs servent uniquement à organiser le rapport.

Ils ne remplacent jamais les analyses.

---

# ÉTAPE 4
## Construire le portrait relationnel

Assembler les informations provenant de plusieurs évaluations.

Le portrait ne dépend jamais d'un seul questionnaire.

Le portrait doit résumer :

- la manière d'aimer ;
- la manière de communiquer ;
- la manière de décider ;
- la manière de gérer les émotions ;
- la manière de vivre une relation.

---

# ÉTAPE 5
## Identifier les forces

Sélectionner automatiquement les compétences les plus développées.

Critères :

- score élevé ;
- cohérence entre plusieurs tests ;
- impact positif dans une relation.

Maximum :

5 forces.

---

# ÉTAPE 6
## Identifier les points de vigilance

Repérer les domaines ayant le plus d'impact sur une future relation.

Ne jamais présenter plus de cinq priorités.

Chaque priorité doit être accompagnée :

- d'une explication ;
- d'une recommandation ;
- d'une action.

---

# ÉTAPE 7
## Sélectionner les contenus

Rechercher dans la bibliothèque :

- les analyses adaptées ;
- les conseils ;
- les exercices ;
- les ressources ;
- les modules.

Les contenus sont choisis selon les règles définies dans REPORT_RULES.md.

---

# ÉTAPE 8
## Construire les chapitres

Créer uniquement les chapitres pouvant être alimentés.

Les chapitres incomplets restent visibles.

Ils expliquent :

- pourquoi ils sont incomplets ;
- quel test permettra de les enrichir.

---

# ÉTAPE 9
## Générer les recommandations

Pour chaque priorité :

associer automatiquement :

- un exercice ;
- un module Alliance ;
- une ressource complémentaire ;
- une première action.

Les recommandations doivent être immédiatement utiles.

---

# ÉTAPE 10
## Générer le plan de progression

Construire une feuille de route personnalisée.

Le plan répond à trois questions.

Que développer en priorité ?

Pourquoi ?

Par quoi commencer ?

Maximum :

5 actions.

---

# ÉTAPE 11
## Contrôle qualité

Avant la publication du rapport, vérifier automatiquement :

- aucune contradiction ;
- aucune répétition importante ;
- aucun contenu vide ;
- aucune analyse sans recommandation ;
- aucun chapitre incomplet sans explication.

---

# ÉTAPE 12
## Génération finale

Assembler toutes les sections dans l'ordre défini par REPORT_STRUCTURE.md.

Produire un rapport :

- fluide ;
- cohérent ;
- agréable à lire ;
- professionnel.

---

# Gestion des données manquantes

Les données absentes ne constituent jamais une erreur.

Elles deviennent une opportunité d'évolution.

Chaque section verrouillée doit :

- expliquer son intérêt ;
- indiquer le test nécessaire ;
- encourager le membre à poursuivre son parcours.

---

# Mise à jour du rapport

Chaque nouveau test relance automatiquement ce pipeline.

Le rapport est entièrement régénéré.

Ainsi :

- le portrait devient plus précis ;
- les recommandations évoluent ;
- certaines conclusions peuvent être enrichies ;
- de nouveaux chapitres apparaissent.

Le rapport est donc vivant.

---

# Principe fondamental

LIA ne rédige jamais un rapport à partir d'une page blanche.

Elle applique systématiquement ce pipeline.

La qualité du Rapport Personnalisé Alliance repose sur la rigueur de ce processus, et non sur l'improvisation de l'intelligence artificielle.
