**Version :** 1.0

---

# OBJECTIF

Cette bibliothèque contient tous les textes standardisés utilisés dans le Rapport Personnalisé Alliance.

Elle garantit :

- une identité rédactionnelle cohérente ;
- un ton homogène ;
- une expérience Premium identique pour tous les membres.

Ces textes peuvent être réutilisés automatiquement par LIA.

---

# TON DE KELIAA

Tous les textes doivent être :

- bienveillants ;
- encourageants ;
- simples ;
- élégants ;
- respectueux.

Ils ne doivent jamais :

- culpabiliser ;
- dramatiser ;
- juger ;
- faire peur.
