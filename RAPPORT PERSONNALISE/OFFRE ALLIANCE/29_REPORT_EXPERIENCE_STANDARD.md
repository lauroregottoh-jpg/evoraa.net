# KELIAA ALLIANCE
## Standard d'Expérience du Rapport Personnalisé

**Version :** 1.0

---

# OBJECTIF

Ce document définit le niveau d'expérience que doit offrir le Rapport Personnalisé Alliance.

Le rapport n'est pas seulement un document.

C'est l'un des principaux produits de KELIAA.

Chaque membre qui le consulte doit avoir le sentiment de recevoir un document conçu spécialement pour lui.

---

# LA PROMESSE

Après avoir lu son rapport, le membre doit pouvoir dire :

> "Je me comprends mieux."

> "Je sais quelles sont mes qualités."

> "Je comprends ce que je dois améliorer."

> "Je sais quelle est ma prochaine étape."

Si ces quatre objectifs ne sont pas atteints, le rapport n'a pas rempli sa mission.

---

# CE QUE LE RAPPORT DOIT APPORTER

Le rapport doit permettre au membre de :

- mieux se connaître ;
- comprendre ses comportements relationnels ;
- prendre conscience de ses ressources ;
- identifier ses axes de progression ;
- préparer plus sereinement son futur mariage.

---

# CE QUE LE RAPPORT NE DOIT PAS ÊTRE

Le rapport ne doit jamais être :

- une liste de scores ;
- un diagnostic psychologique ;
- un jugement ;
- un document culpabilisant ;
- une publicité.

Le membre doit avoir envie de le conserver.

---

# LE PARCOURS DE LECTURE

Le rapport suit une progression naturelle.

## Étape 1

Accueillir.

Le membre découvre son rapport.

---

## Étape 2

Comprendre.

Il découvre son fonctionnement.

---

## Étape 3

Valoriser.

Il découvre ses principales qualités.

---

## Étape 4

Progresser.

Il identifie les compétences à développer.

---

## Étape 5

Agir.

Il repart avec des actions concrètes.

---

# LES ÉMOTIONS À SUSCITER

Pendant la lecture, le membre doit ressentir :

- de la curiosité ;
- de la compréhension ;
- de la confiance ;
- de l'encouragement ;
- de l'espérance.

Le rapport ne doit jamais provoquer :

- de la honte ;
- de la peur ;
- du découragement.

---

# LES QUESTIONS AUXQUELLES LE RAPPORT DOIT RÉPONDRE

À la fin de sa lecture, le membre doit connaître les réponses aux questions suivantes :

- Qui suis-je dans une relation ?
- Quelles sont mes principales qualités ?
- Quels comportements dois-je améliorer ?
- Quels sont mes prochains objectifs ?
- Quelle évaluation devrais-je réaliser ensuite ?

---

# LES APPELS À L'ACTION

Le rapport ne doit proposer qu'un nombre limité d'actions.

Priorité :

1. Réaliser une nouvelle évaluation pertinente.
2. Réserver une séance de coaching si nécessaire.
3. Approfondir une thématique importante.

Ne jamais multiplier les appels à l'action.

---

# LA PLACE DES ÉVALUATIONS À DÉBLOQUER

Les évaluations non réalisées ne sont jamais cachées.

Elles sont présentées comme des opportunités.

Chaque carte doit montrer :

- ce que le membre découvrira ;
- pourquoi cette évaluation est utile ;
- comment elle enrichira le rapport.

---

# LE COACHING

Le coaching est proposé lorsque cela apporte une réelle valeur.

Le rapport n'insiste jamais de manière excessive.

Le message doit être naturel.

Exemple :

"Si vous souhaitez approfondir cette thématique et bénéficier d'un accompagnement personnalisé, vous pouvez réserver une séance de coaching."

---

# LA LONGUEUR

Le rapport doit rester agréable à lire.

Objectif :

- 10 à 15 pages PDF ;
- lecture fluide ;
- sections courtes ;
- informations utiles.

---

# LA QUALITÉ VISUELLE

Le rapport doit donner une impression Premium.

Privilégier :

- des cartes ;
- des espaces ;
- des icônes discrètes ;
- une hiérarchie claire.

Éviter :

- les blocs de texte trop longs ;
- les tableaux complexes ;
- les couleurs agressives.

---

# LE NIVEAU DE PERSONNALISATION

Le membre doit reconnaître son profil.

Les exemples, conseils et analyses doivent être directement liés à ses résultats.

Deux rapports ne doivent jamais sembler identiques.

---

# LES MISES À JOUR

Chaque nouvelle évaluation doit enrichir automatiquement :

- le résumé ;
- le portrait relationnel ;
- les analyses ;
- les recommandations ;
- la progression.

Le membre doit constater que son rapport évolue réellement.

---

# LES INDICATEURS DE RÉUSSITE

Le Rapport Personnalisé est considéré comme réussi si :

- le membre le lit jusqu'à la fin ;
- il comprend ses résultats ;
- il réalise une nouvelle évaluation ;
- ou il réserve une séance de coaching.

Ces indicateurs montrent que le rapport remplit son rôle d'accompagnement.

---

# PRINCIPE FONDAMENTAL

Le Rapport Personnalisé Alliance n'a pas pour objectif d'impressionner.

Il a pour objectif d'accompagner.

Chaque page doit aider le membre à mieux se connaître, à progresser concrètement et à avancer avec confiance dans sa préparation au mariage.

Le rapport doit toujours donner plus de clarté, plus d'espérance et plus de direction que lorsque le membre a commencé sa lecture.
