# ALLIANCE PERSONALIZED REPORT™
## Structure du Rapport Personnalisé

**Version :** 1.0

---

# Objectif

Ce document définit la structure officielle du Rapport Personnalisé Alliance.

Chaque rapport généré doit respecter cette organisation afin d'offrir une expérience cohérente, professionnelle et évolutive.

Toutes les sections ne sont pas obligatoirement remplies lors de la première génération.

Certaines analyses apparaîtront uniquement lorsque les tests correspondants auront été complétés.

Le rapport est donc un document vivant qui s'enrichit progressivement.

---

# PAGE 1 — COUVERTURE

Objectif :

Créer immédiatement une forte valeur perçue.

Contenu :

- Nom du membre
- Photo (si disponible)
- Date de génération
- Version Alliance
- Titre

> Votre Rapport Personnalisé Alliance™

Sous-titre :

> Découvrez vos forces, vos axes de progression et votre niveau actuel de préparation à une relation durable.

---

# PAGE 2 — RÉSUMÉ EXÉCUTIF

Objectif :

Donner une vision globale.

Contenu :

- Indice Global de Préparation Relationnelle
- Nombre de tests complétés
- Nombre de tests restants
- Nombre de recommandations personnalisées
- Nombre de modules recommandés

Puis un résumé rédigé par LIA.

Maximum : 300 mots.

---

# PAGE 3 — VOTRE PORTRAIT RELATIONNEL

Objectif :

Répondre à la question :

**Qui êtes-vous dans une relation ?**

Cette section est entièrement personnalisée.

Elle rassemble plusieurs dimensions provenant des tests disponibles.

Le portrait doit être :

- humain
- équilibré
- encourageant
- réaliste

Aucun vocabulaire clinique.

---

# PAGE 4 — VOS PRINCIPALES FORCES

Objectif :

Mettre en valeur les ressources naturelles du membre.

Chaque force comporte :

- un titre
- une explication
- son impact positif dans une relation
- un conseil pour continuer à la développer

Maximum :

5 forces.

---

# PAGE 5 — VOS POINTS DE VIGILANCE

Objectif :

Identifier les domaines qui méritent un travail particulier.

Chaque point comprend :

- une explication
- les conséquences possibles
- une recommandation
- une action concrète

Le ton reste bienveillant.

---

# PAGE 6 — COMMUNICATION

Objectif :

Présenter le fonctionnement du membre dans les échanges.

Cette section peut inclure :

- style de communication
- qualité d'écoute
- affirmation de soi
- expression émotionnelle
- gestion des désaccords

Si le test n'est pas complété :

Afficher une section verrouillée.

---

# PAGE 7 — GESTION DES CONFLITS

Objectif :

Comprendre les réactions face aux tensions.

Exemples :

- fuite
- confrontation
- médiation
- recherche de compromis

Cette page présente :

- le style dominant
- les forces
- les risques
- les conseils

---

# PAGE 8 — INTELLIGENCE ÉMOTIONNELLE

Objectif :

Présenter la manière dont le membre :

- identifie ses émotions
- les comprend
- les régule
- les exprime

Puis proposer un plan d'amélioration.

---

# PAGE 9 — VALEURS FONDAMENTALES

Objectif :

Identifier les convictions qui guideront les décisions importantes.

Peut inclure :

- foi
- famille
- fidélité
- honnêteté
- service
- travail
- argent

---

# PAGE 10 — VISION DU MARIAGE

Objectif :

Présenter la vision personnelle du couple.

Exemples :

- rôle du mariage
- engagement
- leadership
- mission du couple
- priorités

Si le test n'est pas disponible :

Afficher une invitation à compléter le questionnaire.

---

# PAGE 11 — PROJET DE VIE

Objectif :

Présenter les aspirations à long terme.

Peut inclure :

- enfants
- carrière
- ministère
- lieu de vie
- style de vie
- équilibre famille/travail

---

# PAGE 12 — GESTION DES FINANCES

Objectif :

Présenter la relation du membre avec l'argent.

Exemples :

- dépenses
- épargne
- générosité
- sécurité financière
- décisions budgétaires

---

# PAGE 13 — SPIRITUALITÉ

Objectif :

Présenter la place de Dieu dans la future relation.

Peut inclure :

- vie de prière
- maturité spirituelle
- vision biblique du mariage
- service
- communion

---

# PAGE 14 — SYNTHÈSE DES COMPÉTENCES RELATIONNELLES

Objectif :

Afficher les grands indicateurs.

Exemple :

- Communication
- Empathie
- Gestion émotionnelle
- Résolution des conflits
- Vision
- Valeurs
- Spiritualité

Cette page est essentiellement graphique.

---

# PAGE 15 — PLAN DE PROGRESSION PERSONNALISÉ

Objectif :

Transformer les analyses en actions.

Pour chaque priorité :

- objectif
- pourquoi c'est important
- première action
- exercice conseillé
- module recommandé

Maximum :

5 priorités.

---

# PAGE 16 — RESSOURCES ALLIANCE

Objectif :

Orienter le membre vers les contenus les plus pertinents.

Peut inclure :

- modules
- articles
- défis
- podcasts
- vidéos
- exercices
- lectures

Toutes les recommandations sont personnalisées.

---

# PAGE 17 — ÉVOLUTION DE VOTRE RAPPORT

Objectif :

Montrer que le rapport est évolutif.

Afficher :

- tests complétés
- tests disponibles
- prochaines analyses à débloquer

Exemple :

> Complétez le test "Vision du mariage" pour débloquer votre analyse du projet de vie.

---

# PAGE 18 — CONCLUSION

Objectif :

Clôturer le rapport de manière inspirante.

La conclusion doit :

- résumer les principaux enseignements
- encourager le membre
- rappeler que la croissance est progressive
- valoriser le chemin parcouru
- inviter à poursuivre son parcours Alliance

Le rapport doit se terminer sur une note d'espérance, de confiance et de progression.

---

# RÈGLE GÉNÉRALE

Aucune section ne doit disparaître lorsqu'un test manque.

À la place :

- la section reste visible ;
- son intérêt est expliqué ;
- les données manquantes sont signalées ;
- le membre est invité à compléter le test correspondant.

Le rapport donne ainsi une vision claire de ce qui est déjà connu et de ce qui pourra être découvert au fil du parcours.
